Feature Showcase

umm의 핵심 인터랙션 둘러보기

직관적인 공간 캔버스부터 밤사이 자라나는 Dream, 엔터프라이즈 보안까지 모든 기능을 확인하세요.

React Flow 기반 무한 생각 캔버스

문서나 폴더 구조의 제약 없이 2차원 공간 위에 자유롭게 생각을 배치하고 연결합니다. 저장 버튼 없이 모든 변경사항이 실시간 커밋됩니다.

  • ✓ 더블클릭, N, /, 하단 Quick Capture 바 지원
  • ✓ 부드러운 Zoom/Pan, 미니맵, 컨트롤 및 도트 그리드 배경
  • ✓ PostgreSQL LISTEN/NOTIFY 기반 다중 사용자 실시간 동기화

7종 시맨틱 파스텔 포스트잇 & 리사이즈

노랑, 파랑, 보라, 라벤더, 초록, 빨강, 회색의 은은한 종이 질감 색상으로 생각의 맥락을 분류하고 자유롭게 크기를 조절합니다.

  • ✓ 노드 경계면 리사이저로 크기 및 위치 조정
  • ✓ 메모 버전 히스토리 스냅샷 및 언제든 이전 시점으로 복원
  • ✓ Cmd+Z / Shift+Cmd+Z 위치 이동 Undo/Redo 지원

Thought Gravity & 오프라인 의미 연관성

원하는 생각을 선택하고 Gravity를 발동하면 연결된 생각들이 중심 노드 주위로 아름다운 원형 궤도를 그리며 정렬됩니다.

  • ✓ 192차원 n-gram 해싱 기반 외부 AI 없이도 연관 생각 자동 추천
  • ✓ 요약, 질문 만들기, 확장, 반대 관점, 실행 항목 5대 AI 발전 도구
  • ✓ Markdown, 2000px 투명 PNG, A4 PDF 1클릭 내보내기

밤사이 자라난 한 장의 메모, Dreams

사용자가 쉬는 동안 축적된 메모들을 분석하여 새로운 연결과 영감을 주는 질문을 담은 Dream 카드를 생성합니다.

  • ✓ 품질 점수(Quality Score %)와 AI 추론 유형 표시
  • ✓ Quiet Mode: 확실한 통찰이 있을 때만 선별 생성
  • ✓ 클릭 한 번으로 내 캔버스에 라벤더 포스트잇으로 즉시 안착

최소 권한 Scoped API Key & 무중단 키 회전

필요한 권한 스코프만 최소로 부여하고, 설정된 중첩 시간(예: 24시간) 동안 구/신규 키를 동시 지원하는 무중단 키 회전을 제공합니다.

  • ✓ 8종 세부 스코프 선택 및 일회성 Bearer 토큰 발급
  • ✓ Model Context Protocol (POST /mcp) 에이전트 도구 완벽 지원
  • ✓ 즉시 폐기(Revoke) 및 만료 주기 관리

운영 관측성 & 실시간 Dream 비용 대시보드

전체 사용자, 활성 생각 수, 공간 수, AI 호출량, 예상 월 비용($) 및 Dream 유지율/발전율 지표를 한눈에 파악합니다.

  • ✓ Dream 품질 및 비용 산정 실시간 대시보드
  • ✓ 즉시 큐 생성 버튼을 통한 수동 Dream 실행
  • ✓ Keycloak OIDC SSO Discovery 연동 및 그룹 역할 매핑

최대 256K 토큰 지원 & 불변 감사 로그

초거대 Context Window 모델을 위한 256K 토큰 슬라이더와 모든 관리자 행위를 위변조 없이 영구 기록하는 감사 추적 체계를 갖추었습니다.

  • ✓ 4K부터 256K까지 응답 토큰 한도 제어
  • ✓ 내부 OpenAI 호환 LLM Gateway 타임아웃 및 재시도 구성
  • ✓ 추가 전용(Append-only) 불변 감사 로그 테이블
Architecture

엔터프라이즈 폐쇄망을 위한 3대 아키텍처

외부 통신 없이 단일 Docker 컨테이너와 PostgreSQL만으로 영구 지속되는 안정성을 보장합니다.

⚡

오프라인 의미 연관성 엔진

192차원 문자 n-gram feature hashing과 cosine similarity를 DB 내부에서 고속 연산하여 외부 임베딩 API 없이도 연관 생각을 완벽히 추천합니다.

🔄

낙관적 동시성 & 실시간 SSE

모든 노드의 단조 증가 version 번호로 충돌을 방지하며, PostgreSQL LISTEN/NOTIFY 기반 SSE 이벤트로 모든 참여자에게 실시간 반영됩니다.

🌙

분산 야간 Dream 스케줄러

외부 메시지 브로커 없이 PostgreSQL FOR UPDATE SKIP LOCKED를 활용해 다중 워커 간 중복 없이 안전하게 야간 추론 작업을 수행합니다.

Quick Start

4개 환경변수로 30초 만에 시작하기

오프라인 환경에서도 단 한 줄의 명령어로 즉시 기동할 수 있습니다.

Docker 컨테이너 1줄 실행 가이드
docker run -d --name umm --restart unless-stopped \ -p 8080:8080 \ -e POSTGRES_DSN='postgres://umm:password@postgres.internal:5432/umm?sslmode=require' \ -e BOOTSTRAP_ADMIN='admin' \ -e BOOTSTRAP_ADMIN_PASSWORD='your-strong-password' \ -e ENCRYPTION_KEY='your-32-char-random-encryption-key' \ umm:v0.5.1
