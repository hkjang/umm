# v0.26.0 — 결정 기록

여섯 달 뒤에 하는 질문은 "내가 뭘 적었더라"가 아닙니다. **"이거 어떻게 하기로 했더라, 왜?"**입니다.

그리고 가장 먼저 사라지는 건 **왜**입니다. 아쉬워질 무렵이면 알던 사람도 이미 잊었습니다.

## 무엇이 달라지나

왼쪽 메뉴에 **결정 기록**이 생겼습니다. 시간순으로, 공간을 가로질러, 표시한 것만 보여 줍니다.

```
답을 찾음    2026. 8. 23. · 갈래 확인
배포 승인은 누가 해야 하나
  답: 당번제로 하고 주간 회고에서 바꾼다

접어 둠      2026. 8. 23. · 갈래 확인
젠킨스로 이전
  이유: 플러그인 호환 부담이 직접 통제로 얻는 것보다 컸습니다
```

**이유가 결정 옆에 있습니다.** 한 번 더 눌러야 나오는 곳이 아니라. 먼저 사라지는 쪽이 그쪽이라서요.

네 가지가 남습니다. 갈래를 **채택**했을 때, 갈래를 **접어 뒀**을 때, 질문에 **답을 표시**했을 때,
두 생각을 **상충으로 표시**했을 때.

## 지어내지 않습니다

활동이 몰린 주를 읽고 "전환점"이라고 부르지 않습니다. 한 달 조용한 갈래를 접힌 것으로 처리하지도
않습니다.

**결정과 추측이 섞인 기록은 기록이 없는 것보다 나쁩니다.** 정작 필요할 때 어느 쪽이 어느 쪽인지
구분할 수 없기 때문입니다.

비어 있으면 이렇게 말합니다:

> 아직 표시한 결정이 없습니다. **표시된 것이 없다는 뜻이지, 아무 일도 없었다는 뜻은 아닙니다.**

## 아직 정하지 않은 갈래는 여기 없습니다

정해진 게 없으니까요. 진행 중인 갈래까지 넣으면 결정 기록이 **할 일 목록**이 됩니다.

## 정렬은 SQL에서 합니다

네 종류를 각각 최근 120개씩 가져와 Go에서 합치면, 흔한 종류의 최근 항목이 드문 종류의 오래된 항목을
밀어냅니다. 그러면 **"그 해에는 아무것도 결정하지 않았다"**처럼 읽힙니다. 그래서 UNION으로 합친
뒤에 자릅니다.

## 확인한 것

- 전체 Go 테스트 통과, 웹 53개 통과, 타입·린트·i18n 통과
- 표시하지 않은 생각과 진행 중인 갈래가 기록에 나타나지 않는지 통합 테스트로 고정
- 볼 수 없는 공간의 결정이 새지 않는지 고정
- 순서가 최신순인지 고정 — 기록에서 순서가 전부입니다
- 실제 데이터로 화면 확인: 결정과 이유가 함께 나옵니다
