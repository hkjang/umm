# v0.27.0 — 접어 둔 걸 다시 쓰고 있을 때

v0.24.0에서 갈래를 접어 두고, v0.26.0에서 결정을 기록했습니다. 그런데 기록은 **찾아봐야** 보입니다.

정작 필요한 순간은 **다시 쓰고 있을 때**입니다.

## 무엇이 달라지나

오늘의 리뷰에서 거의 같은 두 생각을 찾았을 때, **한쪽이 접어 둔 갈래에 있으면** 다르게 말합니다.

기존:
```
My Space · 97%
배포를 젠킨스로 옮긴다
배포를 젠킨스로 옮긴다              [하나로 합치기]
```

지금:
```
접어 둔 갈래를 다시 쓰고 있습니다 · 젠킨스로 이전
배포를 젠킨스로 옮긴다
접어 둔 이유: 플러그인 호환 부담이 직접 통제로 얻는 것보다 컸습니다
```

**결정만으로는 부족하고 이유가 함께 와야 합니다.** "그거 안 하기로 했잖아"만 남으면, 왜인지 모른 채
다른 이유로 다시 거절하거나, 아예 거절하지 않게 됩니다.

## 여기서는 "하나로 합치기"를 빼습니다

합치면 **먼저 적은 쪽이 남습니다.** 접어 둔 생각이 먼저 적힌 쪽이므로, 한 번 누르면 지금 쓰고 있는
생각이 **이미 거절한 갈래 안으로 조용히 접혀 들어가고**, 남는 건 거절된 쪽입니다.

버튼 하나로 할 일이 아닙니다. 결정과 이유를 보여 주고, 어떻게 할지는 사람이 정합니다.

## 양쪽이 다 접어 둔 갈래에 있으면 표시하지 않습니다

그건 그냥 중복 두 개입니다. 결정을 거스르는 일이 벌어지고 있지 않습니다 — 결정이 둘 다를 덮고
있으니까요. 진행 중이거나 채택한 갈래도 마찬가지로 표시하지 않습니다. 그건 생각의 평범한 상태입니다.

## 이건 측정된 임계값 하나에 기댑니다

umm의 모든 유사도 기준은 분포 상대적입니다. **딱 하나, 근접 중복만 절대값(0.92)**입니다. 두 모델에서
실제 중복이 0.943~0.986에 모이고 그다음 등급은 0.681에서 끊기기 때문입니다.

그래서 이 기능도 **의미를 재는 백엔드에서만** 동작합니다. 기본 로컬 임베딩에서는 오늘의 리뷰가
이미 그렇듯 "재지 않았음"으로 건너뜁니다 — 어휘가 겹치는 것을 중복이라 부르면 접어 둔 결정을 엉뚱한
생각에 들이대게 됩니다.

## 확인한 것

- 전체 Go 테스트 통과, 웹 53개 통과, e2e 17개 통과
- 한쪽만 접어 둔 갈래일 때만 표시되는지 통합 테스트로 고정
- 양쪽 다 같은 갈래, 다시 연 갈래에서는 표시되지 않는지 고정
- 이유가 표시와 함께 오는지 고정
