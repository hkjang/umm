# v0.31.1 — 사람이 지나는 길을 테스트가 지나갑니다

v0.30.1에서 갈래를 **만들 방법이 없다**는 걸 뒤늦게 알았습니다. API는 처음부터 잘 됐고, 화면에는
입구가 없었습니다.

그 뒤로 브라우저로 하나씩 다시 봤고, 확인한 것들을 이제 **테스트로 고정**했습니다.

## 새 e2e 테스트

빈 공간에 생각 하나를 적은 상태에서 시작합니다. 관련된 생각이 없으니 "관련 N" 칩도 없습니다 —
**정확히 v0.30.1에서 깨져 있던 상태**입니다.

1. 메모 메뉴 → **연결과 갈래**
2. 갈래 만들기
3. 갈래 메뉴 → **접어 두기**
4. **이유 없이는 "남기기" 버튼이 눌리지 않는지** 확인
5. 이유를 적고 남기기 → `접어 둠` 표시 확인
6. **결정 기록** 페이지로 이동 → 갈래 이름과 **이유**가 그대로 있는지 확인

마지막이 요점입니다. 몇 달 뒤에 사람이 찾아볼 자리에서 **결정과 이유가 같이** 나오는지를
브라우저가 확인합니다.

이유를 필수로 만든 건 스키마 CHECK와 API 양쪽에서였는데, **화면이 그 선을 지키는지는** 확인한 적이
없었습니다. 이제 합니다.

## 왜 이렇게까지

세 릴리스 동안 API는 정확히 답했고 기능은 닿을 수 없었습니다. **기능이 닿을 수 있는지를 말해 주는
것은 브라우저뿐입니다.**

- 전체 Go 테스트 통과, 웹 53개 통과
