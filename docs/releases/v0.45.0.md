# v0.45.0 — 홈 화면이 지금 어디쯤인지 압니다

홈(`/` → `오늘의 리뷰`)을 **빈 계정**과 **오래 쓴 계정** 두 상태로 열어 재 봤습니다.
같은 순서, 같은 블록이 나왔습니다. **처음 온 사람과 매일 오는 사람에게 같은 화면**이었고,
어긋난 곳은 거기였습니다.

## 첫 아침의 첫 문장이 안내가 아니었습니다

생각이 **0개**인 계정에서 제목 바로 아래에 이렇게 떠 있었습니다.

> 겹치는 생각은 확인하지 못했습니다. 지금 임베딩은 뜻이 아니라 단어 겹침을 재기 때문에,
> 찾아 봤자 표현이 비슷한 것만 나옵니다.

```
morning-brief (생각 0개):
  dreams []  suggestions 0  unfiled 0  duplicates []  questions []
  skipped [{duplicates, backend-not-semantic}]
  quiet   false      ← "건너뛴 게 있으니 조용한 아침이 아니다"
```

건너뛴 게 아닙니다. **볼 게 없었습니다.** 중복은 짝이라 둘이 있어야 성립하는데, 이 사람은
아직 하나도 안 썼습니다.

`skipped`는 "빈 목록을 이상 없음으로 읽지 말라"고 있는 장치입니다. 비교하지 못한 생각이
쌓인 사람에게는 꼭 필요하고, 아직 두 개를 쓰지 않은 사람에게는 **처음 보는 화면의 첫
문장이 기술적 변명**이 됩니다. 이제 **비교할 게 둘 이상일 때만** 말합니다.

## 다 한 안내가 끝나지 않았습니다

네 단계를 다 마친 계정에서 측정한 값입니다.

```
안내 카드   진행률 100%  ·  4/4 완료  ·  높이 517px
위치        모든 실제 내용보다 위
사라지는 조건  '안내 마치기' 회색 링크를 직접 누를 때만
```

안내가 시키는 걸 다 했는데도 **매일 아침 같은 체크리스트**를 지나야 했습니다. 남은 항목이
없는 체크리스트는 안내가 아니라 가구입니다. 이제 **마지막 단계가 끝나면 스스로 닫힙니다.**

## 숫자와 목록이 서로 다른 말을 했습니다

오래 쓴 계정에서 타일과 목록을 나란히 세어 봤습니다.

| | 타일이 센 것 | 목록이 보여준 것 | 화면의 설명 |
| --- | --- | --- | --- |
| **다시 볼 생각** | **12** | **8** | 없음 |
| 연결 대기 | 1 | 1 | — |
| 새 Dream | 2 | 2 | — |
| 함께한 활동 | 0 | 0 | — |

타일은 진짜 총계를 세고, 목록은 각각 8·6·5·8개에서 잘립니다. 세어 보면 여덟 장인데 옆에는
12라고 적혀 있고, **둘을 맞춰 볼 단서가 화면에 없습니다.** 빠진 넷은 사라진 게 아니라
앞의 것을 처리하면 올라옵니다 — 그걸 알 방법이 없었을 뿐입니다.

**다 치웠다고 믿는 대기열이, 아직 남은 대기열보다 나쁩니다.**

이제 네 섹션 모두 자기가 무엇을 덜 보여 주는지 말합니다.

> 오래되었거나 직접 다시 보기로 한 메모입니다. **12개 중 8개를 보여드립니다.**
> 검토하거나 미루면 다음 생각이 올라옵니다.

숨긴 게 없으면 아무 말도 하지 않습니다.

## 기억이 빈 사람에게 기억을 묻게 했습니다

빈 계정의 첫 화면 순서가 이랬습니다.

```
오늘, 이어볼 생각
  내 기억에 물어보기      ← 생각 0개. 무엇을 물어도 "찾지 못했습니다"
  umm을 내 생각 습관에 연결하기
```

답이 나올 수 없는 입력창이 **시작 안내보다 위**에 있었습니다. 안내가 끝나기 전까지는
**안내가 먼저** 옵니다. 안내는 이제 스스로 닫히니, 지나가는 상태이지 머무는 상태가
아닙니다.

## 검증

네 가지를 모두 **되돌려서** 확인했습니다.

```
✘ 안내가 스스로 닫히지 않게 되돌림   → 4/4·100%인데 completed=false 로 실패
✘ 볼 게 없어도 건너뛰었다고 말하게   → 생각 0개 계정에 skip 이 떠서 실패
✘ 짝의 기준을 둘에서 하나로          → 생각 1개 계정에 skip 이 떠서 실패
✘ 덜 보여준다는 말을 지움            → 12개 중 8개 문구 없음으로 실패
✘ 숨긴 게 없어도 항상 말하게         → 두 테스트 모두 실패
✘ 안내를 다시 아래로                 → guide-first 가 ask-first 로 실패
```

기존 테스트 하나가 이번 변경을 잡았습니다. `TestBriefSaysWhatItCouldNotCheck` 는 생각이
**하나도 없는** 계정에서 skip 을 요구하고 있었습니다. 지키려던 성질은 옳지만 그 성질이
성립하는 자리가 아니라, **생각 둘을 넣어** 성질이 실제로 성립하는 계정에서 확인하도록
고쳤습니다.
