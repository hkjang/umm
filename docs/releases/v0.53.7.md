# v0.53.7 — 갈래 패널도 할 수 있는 것만 보여 줍니다

v0.53.6 에서 댓글 메뉴를 맞췄습니다. **갈래 패널이 남아 있었습니다.**

`연결과 갈래` 패널이 하는 일은 전부 쓰기입니다.

```
갈래에 생각 넣기 · 채택 · 접어 두기 · 다시 열기 · 삭제 · 새 갈래 만들기
```

읽기로 초대받은 사람에게 **이 여섯 개가 전부 그대로 보였습니다.** 서버는 전부 거절합니다
(`edit` 이상이어야 합니다). 패널은 권한을 아예 전달받지도 않았습니다.

## 이제

읽기 권한이면 **갈래 메뉴와 새 갈래 입력칸이 나오지 않고**, 배지를 눌러도 갈래에 넣지
않습니다.

**대신 볼 것은 그대로 봅니다** — 이 생각이 어느 갈래인지, 그 갈래가 채택됐는지 접혔는지,
그리고 그 이유까지. 바꾸지 못한다고 해서 **덜 보여 줄 이유는 없습니다.**

## 검증

```
✘ 갈래 메뉴·새 갈래 입력칸을 다시 모두에게  →  읽기 전용 화면에 나타나 시험 실패
```

## 되돌리기가 처음엔 헛돌았습니다

첫 되돌리기는 **적용되지 않았습니다.** Prettier 가 JSX 를 다시 들여쓴 뒤라 제가 잡은 문자열이
파일에 없었고, 치환이 조용히 아무것도 하지 않았습니다. 시험은 통과했고, 그건 "시험이 못
잡는다" 가 아니라 **"아무것도 바꾸지 않았다"** 였습니다.

번들 파일 이름이 그대로인 것을 보고 알았습니다. 줄 번호로 다시 넣으니 번들이 바뀌었고,
그제서야 시험이 실패했습니다.
