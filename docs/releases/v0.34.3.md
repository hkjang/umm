# v0.34.3 — API 문서가 새 칸을 모르고 있었습니다

v0.34.0~v0.34.2로 임베딩 Gateway 분리를 마쳤습니다. 마지막으로 **문서가 그걸 아는지** 확인했더니,
`/admin/ai-gateway/test`의 요청 스키마가 옛 모습 그대로였습니다.

```yaml
required: [base_url, embedding_model]
properties:
  base_url, embedding_model, api_key      # 새 칸 둘이 없음
```

## 두 가지가 틀려 있었습니다

**없는 필드** — `embedding_base_url`·`embedding_api_key`가 빠져 있어, 문서만 보고 연동하는 사람은
임베딩 서버를 지정할 방법을 알 수 없습니다.

**틀린 필수 조건** — `base_url`이 필수로 적혀 있었습니다. 임베딩 주소를 지정하면 **채팅 주소는 없어도
됩니다.** 문서대로면 쓰지도 않을 값을 채워 넣어야 합니다.

이제 **주소 둘 중 하나**가 필요하다고 적고, 어느 쪽을 검사하는지와 그때 어떤 키가 가는지를 함께
설명합니다. 빈 임베딩 키가 "인증 없음"이고 마스킹된 값만 "저장된 것 그대로"라는 규칙도 적었습니다.

설정 저장 설명에도 암호화되는 비밀이 `client_secret`·`api_key` 둘뿐인 것처럼 쓰여 있어
`embedding_api_key`를 더했습니다.

## 분리 구성으로 제품 전체를 돌려 봤습니다

새로 지원하는 구성인데 전체 흐름을 돌려 본 적이 없어서 확인했습니다.

| 확인 | 결과 |
| --- | --- |
| 임베딩 (분리 칸 경유) | bge-m3 · 쌍별 0.833 |
| 연관 생각 | 0.554 / 0.537 |
| 연결 추천 | 3건 |
| 접어 둔 갈래 되짚기 | 이유와 함께 표시 |
| 기억에 묻기 | 결정과 이유를 정확히, 근거에 `abandoned` |
| 조력자 | 도구 연쇄 정상 |
| 결정 기록 | 정상 |

**새로 발견된 결함은 없습니다.**
