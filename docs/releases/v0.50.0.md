# v0.50.0 — Ptium 키가 저장되고, 폐기한 키를 목록에서 지울 수 있습니다

보고해 주신 두 가지를 재현하고 고쳤습니다.

## 1. Ptium 키가 저장될 때마다 지워지고 있었습니다

저장은 됩니다. **다시 저장할 때 지워집니다.**

```
저장           api_key = enc:v2...   ← 암호화되어 들어감
화면 새로고침   api_key = ••••••••    ← 화면은 마스크를 보여 줍니다
다시 저장       api_key = (빈 값)     ← 마스크가 그대로 덮어씀
```

그래서 Ptium을 설정하고, 돌아와서, **그 섹션에서 아무거나 하나만 바꿔 저장해도** 키가
사라졌습니다.

원인은 목록 하나입니다. 저장 경로는 마스크가 오면 그 필드를 **빼고** 넘기고, 저장소가
기존 암호문을 **합쳐 주기를** 기대합니다. 그런데 그 병합은 섹션 이름 목록으로 돌고 있었고
**ptium 이 거기 없었습니다.**

```go
case "security":   ...
case "oidc":       ...
case "ai_gateway": ...
// ptium 없음  → 통째로 덮어쓰기
```

ptium 은 **이미 한 번** 이런 목록에서 빠진 적이 있습니다(`AllowedSetting`, 그때는 404 라
바로 보였습니다). 이번엔 조용히 키만 지워졌습니다. 그래서 이번에는 **목록을 하나로
합쳤습니다** — 마스킹하는 필드와 병합하는 필드가 같은 곳에서 나옵니다.

```
저장 → 마스크로 재저장 → 키 유지 (다른 필드는 정상 갱신)
     → 빈 값으로 저장   → 키 유지
     → 새 키 입력       → 교체됨
```

## 2. 폐기한 키가 목록에서 사라지지 않았습니다

`폐기` 는 키를 **정지**시킵니다. 그런데 목록은 지금까지 발급한 키를 **전부** 돌려주고,
폐기된 키에는 **남은 동작이 하나도 없었습니다**(버튼이 비활성). 눌렀는데 그대로 남아
있으니 삭제가 안 되는 것으로 보입니다.

이제 두 걸음입니다.

```
폐기            → 키가 즉시 정지 (되돌릴 수 없음)
목록에서 지우기  → 이미 정지된 키만 목록에서 제거
```

**아직 동작하는 키는 한 번의 실수로 사라지지 않습니다.** 정지가 먼저입니다.

## 3. 권한 변경은 원래 동작하고 있었습니다 — 다만 한 곳이 조용했습니다

발급된 키의 권한 체크박스는 정상 동작합니다(확인했습니다). 다만 **마지막 하나를 끄면**
아무 일도 없이 체크박스만 되돌아왔습니다. 이제 이유를 말합니다.

> 키에는 권한이 하나 이상 있어야 합니다. 이 키를 쓰지 않으려면 폐기해 주세요.

## 검증

되돌려서 확인했습니다.

```
✘ ptium 을 다시 병합 목록에서 뺌   → 저장한 키가 사라져 실패 (+ 목록 일치 검사도 실패)
✘ 폐기 여부 확인 없이 삭제          → "아직 동작하는 키가 지워짐" 으로 실패
```

첫 번째는 **두 테스트가 잡습니다.** 하나는 실제로 저장했다 다시 저장해 보고, 다른 하나는
데이터베이스 없이 **"마스킹하는 필드는 반드시 병합 목록에도 있어야 한다"** 만 확인합니다.
다음에 비밀 값을 가진 섹션이 늘어도 잊히지 않게요.
