# v0.53.2 — 다시 시도해도 자리와 연결이 남습니다

v0.53.1 에서 2000개짜리 공간도 되살릴 수 있게 만들었습니다. 그러면서 **제가 만든 구멍**이
하나 생겼습니다.

가져오기 중 일부가 실패하면 화면은 실패한 것들을 입력란에 되돌려 놓고 이렇게 말합니다.

> N개의 생각을 가져오지 못했습니다. 입력란에 남겨 두었으니 다시 시도해 주세요.

그런데 되돌려 놓는 초안이 **맨 텍스트**였습니다.

```
가져올 때                                       다시 시도용 초안
──────────────────────────────────────────    ──────────────────
본문 + id + 자리(0,0) + 색 + 종류 + 갈래         본문뿐
```

다시 시도하면 그 생각들만 **격자에, 기본 노랑으로, 평범한 생각으로, 갈래 없이** 들어갑니다.
게다가 머리말이 없으니 내보내기로 인식되지 않아서, **200개가 넘으면 다시 상한에 걸립니다** —
v0.53.1 로 막 열어 준 그 문이 닫힙니다.

공간 하나를 통째로 가져올 수 있게 만든 것이 곧 **중간에 끊길 일이 흔해졌다**는 뜻이므로,
이건 이론적인 이야기가 아닙니다.

## 이제

초안이 내보내기에서 온 것이면 **내보내기 형태로** 돌려놓습니다 — 머리말, 생각마다의
메타데이터, 그리고 해당되는 연결과 갈래까지.

```
Exported from umm at 2026-08-26T16:01:02+09:00.

## Thought

이어진 생각의 본문

- id: `bfe3a64a-…`
- type: `thought`
- canvas: `0, 0`
- line: `되돌리기 실험`

## Connections
## Lines of thinking
```

다시 읽으면 `isExport=true`, 생각 2개, 연결 1개, 갈래 1개 — 처음과 같습니다.

## 되살릴 수 없는 것은 적어 둡니다

**성공한 생각으로 이어지던 연결은 되살릴 수 없습니다.** 그 생각은 이미 만들어졌고 **새 id**
를 갖고 있는데, 초안은 그 새 이름을 알 방법이 없습니다. 옛 id 로 적어 두면 조용히 엉뚱한
곳을 가리키거나 그냥 실패합니다. 그래서 **버립니다** — 그리고 그걸 시험으로 고정했습니다.

## 검증

```
✘ 초안을 다시 맨 텍스트로 (= v0.53.1 동작)  →  시험 2개 실패
✘ 양쪽이 다 재시도 대상이 아닌 연결도 유지    →  "버린다" 시험 실패
✘ 머리말을 기억하지 않음                     →  시험 2개 실패
```

## 그리고: 제 시험 환경이 틀렸던 일

e2e 하나가 실패했습니다 — 오프라인 큐 시험입니다. 제 변경 때문인지 확인하려고 **손대지 않은
main 에서도 돌려 봤더니 똑같이 실패**했습니다. CI 에서는 통과합니다.

원인은 제품이 아니라 **제가 계속 재사용한 probe 데이터베이스**였습니다. 공간이 113개까지
쌓였고, 시험이 쓰는 공간의 메모가 25개를 넘으면 캔버스가 **요약 보기**로 열립니다 — 메모가
개별 카드가 아니라 묶음 도형으로 그려지므로, 시험이 찾는 카드가 없습니다.

새 데이터베이스에서는 통과합니다. 앞으로 e2e 는 깨끗한 데이터베이스에서 돌립니다.
