# umm v0.8.0 — 많아져도 버티는 umm

v0.7.0이 "협업을 신뢰할 수 있게" 만들었다면, v0.8.0은 **사람과 생각이 늘어나도 같은 속도로 동작하도록** 서비스의 바닥을 다시 깔았습니다. 여기에 언어·테마·가져오기를 더해 umm을 처음 여는 사람의 진입 장벽도 함께 낮췄습니다.

---

## 1. 규모 — 접속자가 늘어도 데이터베이스는 조용합니다

### 실시간 협업이 폴링에서 푸시로

이전에는 공간을 열어 둔 사람 **한 명당 초당 1회** `space_events`를 조회했습니다. 100명이 조용히 공간을 열어 두기만 해도 초당 100번의 쿼리가 돌았습니다.

이제 인스턴스마다 PostgreSQL `LISTEN` 연결을 **하나만** 유지하고, `space_events`에 걸린 트리거가 커밋 시점에 `pg_notify`로 알립니다. 알림은 프로세스 안에서 구독자에게 팬아웃됩니다.

- 유휴 공간의 데이터베이스 비용: **0**
- 알림이 도착하면 즉시 전달되므로 체감 지연도 최대 1초에서 즉시로 줄었습니다.
- 리스너가 끊기면 자동으로 재연결하고, 그동안에는 예전 폴링 주기로 되돌아가 협업이 멈추지 않습니다.
- 트리거의 `pg_notify`는 커밋된 트랜잭션에만 전달되므로, 롤백된 변경이 다른 사람 화면에 나타나는 일은 구조적으로 불가능합니다.

`/admin/overview`와 Prometheus에서 `umm_realtime_subscribers`, `umm_realtime_listener_up`으로 상태를 볼 수 있습니다.

### 검색이 인덱스를 타기 시작했습니다

키워드 검색은 `NOT EXISTS(... NOT ILIKE ...)` 형태였습니다. 논리적으로는 "모든 단어가 포함된 메모"지만, 이 형태는 **어떤 인덱스도 탈 수 없어** 매 검색마다 모든 메모 본문을 읽었습니다.

- 조건을 `expr ILIKE $1 AND expr ILIKE $2 …`로 펼쳐 각 단어가 `pg_trgm` GIN 인덱스를 타고, PostgreSQL이 비트맵을 교집합하도록 바꿨습니다.
- `notes_text_trgm_idx`, `spaces_name_trgm_idx`, `notes_space_updated_idx`를 추가했습니다.
- 인덱스 표현식과 코드의 표현식이 어긋나면 조용히 순차 스캔으로 돌아가므로, 두 값이 같은지 검사하는 테스트를 함께 두었습니다.

### 캔버스를 열 때마다 하던 불필요한 쓰기 제거

캔버스를 열 때마다 메모 **개수만큼** 임베딩 UPDATE를 날리고 있었습니다(대부분 아무것도 바꾸지 않는 no-op). 이제 데이터베이스에 "어떤 임베딩이 실제로 낡았는지" 먼저 묻고 그것만 다시 계산합니다.

### 연결 풀과 정리 작업

- 풀 크기·수명 기본값을 정하고, 오래 붙잡는 연결(LISTEN, 마이그레이션 잠금) 몫을 확보합니다.
- 만료된 세션·OAuth state·재시도 기록·로그인 실패 기록을 15분마다 정리합니다. 이전에는 **한 번도 삭제되지 않아** 배포 수명 내내 쌓였습니다.

## 2. 임베딩을 고를 수 있습니다

내장 로컬 임베딩(문자 n-gram)은 외부 연결 없이 동작하지만 한국어 재현율이 높지 않습니다.

- 관리자 → AI Gateway에 **임베딩 모델**을 지정하면 OpenAI 호환 `/v1/embeddings`를 사용합니다.
- 비워 두면 지금까지와 똑같이 완전 오프라인으로 동작합니다.
- 벡터에는 알고리즘 이름이 함께 저장되고, **같은 알고리즘끼리만 비교**합니다. 모델을 바꾸면 서로 다른 벡터 공간이 섞이는 대신 점진적으로 다시 임베딩됩니다.
- 게이트웨이 호출이 실패하면 로컬 벡터로 내려가되, **로컬이라고 정직하게 기록**합니다. 실패한 호출이 성공한 것처럼 저장되는 일은 없습니다.

## 3. 보안 — 비어 있던 방어선을 채웠습니다

### 로그인 잠금과 요청 한도

- 로그인 실패는 **데이터베이스에 기록**되어 인스턴스가 여러 대여도 함께 셉니다. 주소별 한도를 넘으면 잠깁니다.
- 계정별 한도는 주소별의 3배입니다. 아이디를 아는 사람이 남의 계정을 마음대로 잠글 수 없어야 하기 때문입니다.
- API 요청은 호출자별 토큰 버킷으로 제한하고 `429`와 `Retry-After`로 응답합니다.
- AI 생성 엔드포인트(`/ai/assist`, Dream 재생성·발전)는 **분당 한도와 하루 한도**를 따로 받습니다. 하루 한도는 `ai_calls`에서 세므로 재시작과 인스턴스를 넘어 유지됩니다.
- 모두 관리자 → 키 · 권한 → **남용 방지**에서 조정합니다.

### Content-Security-Policy를 응답마다 조입니다

- `script-src`가 **응답마다 새로 만드는 nonce + `strict-dynamic`** 이 되었습니다. 주입된 `<script src=…>`는 같은 출처를 가리켜도 실행되지 않습니다.
- `object-src 'none'`, `frame-src 'none'`, `worker-src`, `manifest-src`, COOP/CORP를 추가했습니다.
- TLS로 들어온 요청에만 HSTS를 붙입니다. 평문 HTTP로 평가 중인 배포가 자기 브라우저에서 잠기지 않도록 하기 위해서입니다.
- `style-src`의 `'unsafe-inline'`은 의도적으로 남겼습니다. Mantine이 테마 변수를 런타임 `<style>`로 쓰고 React Flow가 노드마다 style 속성으로 위치를 잡기 때문에, 제거하면 캔버스가 깨지면서 얻는 것은 script 주입보다 훨씬 낮은 등급의 방어뿐입니다. 이 판단은 `docs/SECURITY.md`에 근거와 함께 적어 두었습니다.

### 로그인한 기기 관리

개인 설정에 **로그인한 기기** 카드가 생겼습니다. 브라우저·주소·마지막 활동 시각을 보고 개별 종료하거나 "다른 기기 모두 로그아웃"을 할 수 있습니다. 이전에는 세션 목록도 원격 종료도 없었습니다.

## 4. 검증 — 믿을 수 있는 근거를 CI에 넣었습니다

| 추가한 검증 | 잡아내는 것 |
| :--- | :--- |
| **Playwright E2E 12개** | 실제 바이너리 + 실제 번들에서 로그인, 생각 작성, 오프라인 큐 재동기화, 마크다운 가져오기, 언어·테마 유지, CSP nonce |
| **Vitest 30개** | 오프라인 큐 계정 분리·중복 제거·거부 처리, 번역 폴백과 보간, 마크다운 분할 |
| **다중 인스턴스 스모크** | 인스턴스 A의 쓰기가 B의 이벤트 스트림에 도달하는지, 재시도가 인스턴스를 넘어 멱등한지, 로그인 잠금이 공유되는지 |
| **마이그레이션 dry-run** | 모든 마이그레이션이 적용되고, **다시 적용해도 안전하고**, 되돌릴 수 있는지 |
| **OpenAPI 드리프트 테스트** | 라우터에는 있는데 문서에 없는 엔드포인트, 문서에만 남은 엔드포인트 |
| **번역 커버리지 검사** | `t(...)`를 거치지 않아 영원히 한국어로 남을 문자열 |
| **oxlint + Prettier** | 프론트엔드 정적 검사와 서식 (이전에는 `tsc`뿐) |

E2E는 실제로 버그를 하나 잡았습니다. **재연결 시 오프라인 큐가 두 번 플러시**되어, 같은 변경이 자기 자신의 멱등 예약과 충돌하고 사용자에게 가짜 "버전 충돌" 대화상자를 띄우고 있었습니다. 플러시를 한 번으로 합치고, 진행 중인 예약을 충돌이 아니라 재시도로 다루도록 고쳤습니다.

## 5. 제품 — 처음 열었을 때 비어 있지 않도록

- **English 지원.** 화면 문자열 584개를 전부 번역 계층으로 옮겼습니다. 번역이 없으면 한국어 원문이 그대로 나오므로 화면이 깨지지 않습니다. 언어는 계정 설정이라 다른 브라우저에서도 따라옵니다.
- **다크 모드.** 첫 페인트 전에 테마를 정하므로 밝은 화면이 번쩍이지 않습니다. 포스트잇은 두 테마에서 모두 종이색을 유지합니다 — 제품이 서 있는 은유이기 때문입니다.
- **마크다운 가져오기.** 내보내기만 있고 들어오는 길이 없어서 첫 10분이 빈 캔버스였습니다. 파일이나 붙여넣은 텍스트를 제목·구분선·빈 줄 기준으로 나눠 각각 하나의 생각으로 붙입니다.
- **공유 타깃.** 모바일에서 다른 앱의 공유 시트에 umm이 나타나고, 보낸 내용이 빠른 입력창에 채워집니다.
- **키보드로 생각 편집.** 캔버스에서 Tab으로 이동, Enter로 편집 시작, Esc로 빠져나오기. 방향키 이동은 이전부터 있었지만 편집에 들어갈 방법이 없었습니다.

## 6. 코드 품질

- 프론트엔드 전체를 Prettier로 정리했습니다. 한 줄에 압축돼 있던 화면들이 읽고 리뷰할 수 있는 형태가 됐습니다.
- `AppLayout`에서 알림·외관·오프라인 상태를 별도 컴포넌트로 분리했습니다.
- 개인 설정 저장이 **부분 수정**을 받습니다. 언어만 바꾸려고 Dream 설정 전체를 되돌려 보낼 필요가 없고, 빠뜨려서 지우는 사고도 나지 않습니다.
- `go.mod`의 `go` 지시자를 1.26.0으로 낮추고 `toolchain`을 고정했습니다. Go 1.26 어떤 패치 버전에서도 `GOTOOLCHAIN=local`로 빌드·테스트할 수 있습니다.

## 업그레이드

`docker run`으로 v0.8.0 이미지를 올리면 됩니다. 마이그레이션 007은 기동 시 자동 적용되며 필수 환경변수는 그대로 4개입니다.

```bash
docker run -d --name umm --restart unless-stopped \
  -p 8080:8080 \
  -e POSTGRES_DSN='postgres://umm:password@postgres.internal:5432/umm?sslmode=require' \
  -e BOOTSTRAP_ADMIN='admin' \
  -e BOOTSTRAP_ADMIN_PASSWORD='your-strong-password' \
  -e ENCRYPTION_KEY='your-32-char-random-encryption-key' \
  umm:v0.8.0
```

알아 두면 좋은 것:

- 마이그레이션 007은 `pg_trgm` 확장을 만듭니다. 데이터베이스 사용자에게 `CREATE EXTENSION` 권한이 필요합니다. (기존 마이그레이션도 `pgcrypto`, `citext`를 같은 방식으로 만들고 있었습니다.)
- 트리거를 쓰므로 인스턴스마다 `LISTEN` 연결 하나를 상시 점유합니다. 연결 풀 기본값이 그만큼 여유를 두도록 조정됐지만, `pool_max_conns`를 직접 지정해 두었다면 최소 4 이상인지 확인해 주세요.
- 새 보안 기본값(로그인 8회/15분, 분당 API 600, 분당 AI 6, 하루 AI 80)은 기존 설정을 덮어쓰지 않고 없을 때만 채워집니다.
- 되돌려야 한다면 `migrations/down/007_scale_and_security.down.sql`이 있습니다. 백업을 먼저 확보하세요.
