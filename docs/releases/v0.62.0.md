# v0.62.0 — 묶음 제목만 AI가 짓습니다

지난 릴리즈에서 가까이 둔 생각을 한 슬라이드에 모았습니다. 그런데 그 슬라이드의 **제목**은
여전히 첫 생각의 첫 줄이었고, 첫 생각은 주제가 아니라 그냥 **왼쪽 위에 가장 가까웠던 것**
입니다.

## 먼저, AI 없이 고칠 게 있었습니다

제목을 안 붙인 메모는 본문 첫 줄이 통째로 제목이 됐습니다. 실측:

```
79자: "회고 주기를 격주로 줄이면 논의가 얕아질 수 있다. 대신 주제를 하나로 좁혀서
       깊게 들어가는 편이 나을지 다음 스프린트에 시험해 보기로 했다."
```

이제 **첫 문장**을 씁니다. 첫 문장이 없으면 단어 경계에서 자르고 `…` 를 붙입니다.

**아무것도 잃지 않습니다.** 제목과 본문은 별개 필드라, 잘린 생각은 위에 짧게 뜨고
**아래에 통째로 다시 나옵니다.** 사람이 직접 붙인 제목은 길든 짧든 건드리지 않습니다.

## 그다음이 AI입니다

```
        전                          후
━━━━━━━━━━━━━━━━━━━━━━     ━━━━━━━━━━━━━━━━━━━━━━
회고 주기를 격주로 줄이면      회고 주기 단축          [AI 제목]
논의가 얕아질 수 있다...       ────────────────────
                            회고 주기를 격주로 줄이면
                            논의가 얕아질 수 있다...
                            • 주제를 하나로 좁히기
                            • 다음 스프린트에 시험
```

**제목만 바뀝니다.** 슬라이드 본문은 어느 쪽이든 당신이 쓴 문장 그대로입니다.

## 왜 여기만인가

발표 자료를 남 앞에서 읽을 수 있는 건 **한 줄 한 줄을 본인이 책임질 수 있기 때문**입니다.
읽어 본 적 없는 요약문은 책임질 수 없습니다. 어디서 뜻이 어긋났는지는 발표 중에야 압니다.

그래서 선을 이렇게 그었습니다.

| AI가 하는 것 | AI가 안 하는 것 |
| :--- | :--- |
| 사람이 만든 묶음에 **이름 붙이기** | 사람이 쓴 문장 **다시 쓰기** |

**사람이 만든 걸 이름 붙이는 건 도움이고, 사람이 쓴 걸 다시 쓰는 건 대체입니다.**

연결을 그린 생각은 애초에 대상이 아닙니다 — 자기가 붙인 제목이나 자기 주장이 이미 머리에
있습니다. **위치로 모인 묶음만** 이름을 받습니다.

## 안 되면 그냥 원래대로

```
모델 없음        → 원래 제목
게이트웨이 죽음   → 원래 제목
문장으로 답함    → 원래 제목
여러 줄로 답함   → 원래 제목
JSON 객체로 답함 → 원래 제목
묶음보다 적게 답함 → 못 받은 묶음은 원래 제목
```

**다듬기가 깨진다고 다듬던 것까지 깨지면 안 됩니다.** 게이트웨이가 죽었다고 발표를 못
만들게 하지 않습니다.

이해 못 한 답으로 제목을 만드는 건 특히 안 됩니다. **청중 앞 화면에서야 발견되니까요.**

## 바뀐 걸 숨기지 않습니다

제목이 바뀐 슬라이드마다 **`AI 제목`** 배지가 붙고, 미리보기가 **"묶음 제목 N개를 AI가
지었습니다. 슬라이드 본문은 그대로 당신이 쓴 문장입니다"** 라고 적습니다. 제목의 출처가
조용히 바뀐 덱은 아무도 확인할 수 없습니다.

## 나가는 문 하나로 모았습니다

게이트웨이 호출을 dream 패키지의 `Complete` 하나로 지나가게 했고, **redaction 을 그 안에
넣었습니다.** v0.59.1이 바로 "규칙은 있는데 한 경로가 안 쓰던" 사고였습니다. 호출자가
기억해야 하는 규칙은 언젠가 잊힙니다.

## 확인한 것

```
✓ 제안된 제목이 원래 제목을 대체함
✓ lead·points·From 은 한 글자도 안 바뀜   ← 이 기능이 서 있는 선
✓ 묶음이 아닌 슬라이드는 대상 아님 (모델을 아예 호출하지 않음)
✓ 호출 실패 시 원래 제목 유지
✓ 문장·여러 줄·JSON 객체 답변은 거부
✓ 따옴표와 목록 기호는 형식이므로 벗겨냄
✓ 한 번의 호출, 최대 40묶음, 묶음마다 최대 8개·160자
✓ 긴 제목은 첫 문장으로, 없으면 단어 경계에서 자르고 표시
✓ 잘린 생각은 아래에 통째로 남음
✓ 사람이 붙인 제목은 길어도 그대로
```

변형 넷이 다 잡혔습니다.

| 바꾼 것 | 잡은 것 |
| :--- | :--- |
| 제목과 함께 본문도 바꾸기 | **본문이 바뀜** |
| 실패 시 제목 비우기 | 실패했는데 제목이 사라짐 |
| 문장도 제목으로 허용 | 문장이 제목이 됨 |
| 제목을 안 자르기 | 79자 제목 |
