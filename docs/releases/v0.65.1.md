# v0.65.1 — 아무것도 열지 않는 부 제목

v0.63.0이 긴 발표를 부로 나눴고, v0.64.0이 발표를 시간에 맞췄습니다. 둘을 같이 켜면 **부
제목만 살아남고 그 부의 슬라이드가 전부 잘렸습니다.**

```
    부 3개 · 슬라이드 12장을 8장으로

            전                              후
    ━━━━━━━━━━━━━━━━━━━━━━      ━━━━━━━━━━━━━━━━━━━━━━
    ▸ 문제                       ▸ 문제
        슬라이드 5장                   슬라이드 5장
    ▸ 대안   ← 아래가 없음        ▸ 대안
    ▸ 결정   ← 아래가 없음            슬라이드 1장

    8칸 중 사람의 슬라이드 5칸       8칸 중 사람의 슬라이드 6칸
```

## 부 제목을 사람의 슬라이드와 겨루게 했습니다

분량을 맞추는 일은 슬라이드를 채점해서 무거운 쪽을 남깁니다. 채점은 **그 사람이 한 것**만
읽습니다 — 몇 개의 생각이 이 슬라이드에 닿았는지, 질문으로 표시했는지, 맞섬을 적어
뒀는지.

부 제목에는 그중 아무것도 없습니다. 사람의 문장을 하나도 담지 않고, 생각을 하나도
인용하지 않습니다. **그런 것을 생각 다섯 개가 떠받치는 주장과 나란히 놓고 무게를 비교한
것**이 이 결함입니다. 답은 두 번 틀립니다 — 제목이 자기가 여는 부보다 오래 살고, 그러면서
사람이 말한 분량 중 한 칸을 아무것도 없는 제목에 씁니다.

## 부 제목은 채점하지 않습니다

이제 부 제목은 **그 부에 슬라이드가 남아 있을 때 정확히 그때** 발표에 있습니다. 분량은
사람의 슬라이드에 씁니다.

한 장이 두 칸을 쓸 수 있습니다 — 어떤 부의 첫 슬라이드를 넣으면 그 부의 제목이 따라
들어오니까요. 그래서 안 들어가는 슬라이드는 채우기를 멈추는 대신 지나갑니다. 남은 칸에는
**이미 열린 부의 슬라이드**가 아직 들어갈 수 있고, 사람이 말한 분량은 쓰라고 있는
것입니다.

## 한 장만 남은 부는 제목을 지킵니다

한 장짜리 부는 얇습니다. 그래도 제목을 지우면 **그 한 장이 앞의 부에 조용히
붙습니다** — 그건 아무도 제안하지 않은 나눔입니다. v0.63.0이 모델의 제안을 전부 받거나
전부 버리기로 한 것과 같은 이유입니다.

## 숫자도 같이 고쳤습니다

화면은 `AI가 3개 부로 나눴습니다` 라고 말합니다. 이 숫자는 모델이 **제안한** 개수였고,
분량이 부를 잘라 낸 뒤에도 그대로였습니다. 같은 덱이 3개 부라고 말하면서 2개를 들고 있는
것은 v0.40.1과 같은 모양입니다. 이제 **덱에 남아 있는 부의 개수**입니다.

## 확인한 것

```
✓ 부 제목이 자기 부보다 오래 살지 않음
✓ 부 제목 두 개가 나란히 붙지 않고, 발표가 부 제목으로 끝나지 않음
✓ 8칸이면 8장 — 빈 제목에 쓰던 칸이 사람의 슬라이드로 감
✓ 한 장만 남은 부는 제목을 지킴
✓ 잘린 슬라이드 수와 생각 수는 여전히 전부 보고됨
✓ 화면이 말하는 부 개수 = 덱에 있는 부 개수
✓ 부가 없는 덱(나누기를 안 켠 경우)에서는 v0.64.0과 한 비트도 다르지 않음
```

| 바꾼 것 | 잡은 것 |
| :--- | :--- |
| 부 제목을 무게로 채점 | 아무것도 열지 않는 제목이 남음 |
| 잘라 낸 뒤 부 개수 그대로 | 3개 부라면서 2개를 들고 있음 |
