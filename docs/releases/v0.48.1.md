# v0.48.1 — 오프라인에서 새로고침해도 로그인 화면으로 돌아가지 않습니다

오프라인 동작을 브라우저로 처음 끝까지 걸어 봤습니다. **대부분은 이미 잘 되어 있었습니다.**

```
오프라인 전환   → 배너 "오프라인 · 0개 변경을 안전하게 보관 중"
오프라인 캡처   → 보관함에 1개
기존 메모 수정  → 보관함에 1개
오프라인 새로고침 → 보관함 그대로 1개      ← 살아남습니다
온라인 복귀     → 보관함 0개, 서버에 저장됨
```

서비스 워커도 제대로 있습니다 — **155개를 미리 받아 두고 앱 껍데기까지 캐시**합니다.

## 그런데 새로고침하면 로그인 화면이 나왔습니다

오프라인에서 새로고침하면 껍데기는 잘 떠오는데, 그 위에 이게 있었습니다.

```
연결 오류 · 서버에 연결할 수 없습니다
um  생각부터 붙이세요. 정리는 나중에.      ← 로그인 화면
```

**네트워크 없이는 할 수 없는 단 하나를 요구하고 있었습니다.** 적어 둔 생각은 보관함에
안전했지만, 화면은 지나갈 수 없는 로그인 폼이었습니다.

원인은 한 줄입니다.

```ts
api<User>('/me', { silent: true }).catch(() => undefined)
```

**서버가 "당신은 로그인 상태가 아니다"라고 답한 것**과 **서버에 닿지 못한 것**을 같은 것으로
쓰고 있었습니다. 둘은 이미 구분됩니다 — 네트워크 실패는 `status 0`, 진짜 거절은 `401`.

이제 닿지 못했을 때만 **이 브라우저가 마지막으로 가지고 있던 세션**으로 화면을 유지하고,
서버가 실제로 거절하면 즉시 지웁니다.

```
후:  오프라인 새로고침 → 사이드바 있음 · 로그인 폼 없음 · admin 유지 · 오프라인 배너 표시
```

저장하는 건 껍데기를 그리는 데 필요한 것뿐입니다 — id, 아이디, 표시 이름, 역할. **이메일은
넣지 않았습니다.** 자격 증명이 아니고 자격 증명을 대신하지도 않습니다. 모든 요청은 여전히
쿠키를 들고 가고 판단은 서버가 합니다.

## 검증

양쪽 방향으로 되돌려 확인했습니다.

```
✘ 네트워크 실패를 다시 "로그아웃"으로 → 오프라인 새로고침에서 로그인 폼이 떠 실패
✘ 401 에도 기억한 세션을 유지        → 로그아웃이 안 돼 실패
```

두 번째가 중요합니다. **이 장치가 진짜 로그아웃을 덮어 버리면 안 됩니다.**

## 제 측정이 틀렸던 것 하나

고친 뒤 "오프라인 배너가 안 뜬다"고 잠깐 판단했습니다. 확인해 보니

```
navigator.onLine = true    ← Playwright 의 setOffline 은 요청만 막고 이 값은 그대로 둡니다
```

**제품이 아니라 도구 문제**였습니다. 실제 오프라인 브라우저는 로드 시 `false` 를 보고합니다.
그 값까지 맞춰 다시 재니 배너는 정상이었습니다. 테스트도 같은 방식으로 씁니다.
