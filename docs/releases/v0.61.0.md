# v0.61.0 — 생각 하나가 슬라이드 하나가 아닙니다

생각 2,000개짜리 공간으로 발표를 만들면 **슬라이드가 2,000장** 나왔습니다.

그건 발표가 아니고, 그 공간이 실제로 생긴 모양도 아닙니다.

## 이미 되고 있던 것

연결을 그린 생각은 원래부터 함께 갑니다. 근거는 자기 주장 아래 붙고, 기록된 반대는 한
슬라이드에 양쪽이 같이 오고, `follows` 사슬은 순서가 됩니다. **그건 사람이 직접 말한
것이고, 가장 좋은 신호입니다.**

빠져 있던 건 **말하지 않은 것**이었습니다. 아무 연결도 없는 생각은 무조건 자기 슬라이드를
하나 차지했습니다. 빠르게 적고 선은 안 그린 공간이 노트 수만큼 슬라이드를 만든 이유입니다.

## 캔버스는 이미 답을 알고 있었습니다

멀리서 본 캔버스는 그룹마다 도형 하나를 그립니다. 의미를 판단할 수 없을 때는 **어디에
놓였는지로** 묶습니다 — 생각의 흐름은 한 줄로 늘어놓고, 한 주제는 한 뭉치로 모아 놓기
때문입니다.

덱도 이제 같은 질문을 같은 방식으로 합니다. **요약된 캔버스와 덱이 같은 그룹을 보여 줍니다.**

```
                        전          후
   25 생각            25 장       4 장
  100 생각           100 장      15 장
 1000 생각          1000 장     143 장
 2000 생각          2000 장     286 장
```

흩어놓은 생각은 그대로 각자 한 장입니다. **가까운 게 없으면 읽어 낼 배치가 없고, 그럴 땐
하나씩이 정직한 답입니다.**

## 의미가 아니라 위치로 묶습니다. 일부러입니다

덱 컴파일은 생각과 연결만 받는 순수 함수입니다 — 같은 공간이면 항상 같은 덱이고, 오프라인이며,
임베딩 백엔드가 끼지 않습니다.

의미로 묶으면 덱이 **관리자가 어떤 모델을 설정했는지에 따라 달라집니다.** 게이트웨이를 바꿨더니
덱이 저 혼자 재배치되는 것보다는, 만든 사람이 실제로 한 배치를 따르는 편이 낫습니다.

## 사람이 말한 것이 항상 이깁니다

근거를 위치로 묶어 버리면 자기가 뒷받침하는 주장에서 떨어져 나갑니다. 그래서 **연결이 하나라도
있는 생각은 위치 묶음의 대상이 아닙니다.**

슬라이드 하나에 들어가는 생각도 제한이 있습니다. 넘치면 다음 슬라이드로 이어지고, **버려지지
않습니다.** 시험이 확인하는 건 "슬라이드가 줄었다"가 아니라 **"모든 생각이 정확히 한 장에
도달한다"** 입니다 — 줄이기만 하는 건 잃어버리면 되니까요.

배치가 아무 의미 없는 공간이면 **생각 하나마다 슬라이드 하나**로 끌 수 있습니다.

---

## 그리고 큰 공간이 실패하던 경로

덱 만들기는 호출 두 번입니다. Ptium이 덱을 열고, umm이 소스를 넣습니다. **두 번째가 실패하면
덱은 이미 있고 비어 있습니다.** 다시 누르면 하나가 더 생겼고, **아무도 그 사실을 말해 주지
않았습니다.** 네 번 실패한 공간은 빈 덱 네 개를 남겼습니다.

이제 실패 응답이 그 덱을 지목하고, 화면이 **"만들어진 발표 자료에 이어서 넣기"** 를 제안합니다.
Ptium의 소스 엔드포인트는 덮어쓰기라 두 번 넣어도 한 번 넣은 것과 같습니다. 다시 넣을 때는
저장된 옛 소스를 재생하지 않고 **공간을 다시 컴파일합니다** — 실패한 뒤로 생각이 바뀌었을
테니까요.

그리고 슬라이드가 80장을 넘으면 **보내기 전에** 경고합니다. 그 숫자는 umm이 자기 쪽에서
이미 알고 있습니다.

### 제가 제안했던 것 하나는 못 했습니다

"만들기 전에 dry-run 해보기"를 제안드렸는데, **불가능합니다.** Ptium은 **덱 없이** 소스를
검증하는 엔드포인트가 없습니다 — 템플릿이 슬라이드가 맞는지를 결정하기 때문입니다. 검사용
덱을 만들면 제가 막으려던 바로 그 쓰레기를 만듭니다. 대신 **실패한 덱에 이어 넣기**로 가면
애초에 쌓이지 않습니다.

## 확인한 것

```
✓ 붙여 놓은 생각들이 한 장에 모임
✓ 흩어놓은 생각은 각자 한 장
✓ 연결이 있는 생각은 위치로 재편성되지 않음
✓ 모든 생각이 정확히 한 슬라이드에 도달 (빠짐도 중복도 없음)
✓ 한 장에 담기지 않으면 다음 장으로 이어지고, 이어진 장에도 제목이 있음
✓ 노트 도착 순서가 달라도 같은 덱
✓ 스무 번 돌려도 같은 덱
✓ 크기 기록이 없는 노트도 자리를 차지함
✓ 재시도는 있는 덱에 넣고, Ptium에 덱을 더 만들지 않음
✓ 성공한 덱은 재시도 대상이 아님 (주인 모르게 바뀌면 안 됨)
```

변형 다섯 개가 다 잡혔습니다.

| 바꾼 것 | 잡은 것 |
| :--- | :--- |
| 연결된 생각도 위치로 묶기 | 무관한 생각이 주장 슬라이드에 올라옴 |
| 넘치는 만큼 버리기 | **생각이 아무 슬라이드에도 도달하지 못함** |
| 크기 없는 노트를 점으로 보기 | 붙어 있는 두 노트가 두 장이 됨 |
| 재시도가 새 덱을 열기 | Ptium에 덱이 2개 열림 |
| 성공한 덱도 재시도 허용 | 완성된 덱이 재컴파일됨 |
