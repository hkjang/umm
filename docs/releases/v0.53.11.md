# v0.53.11 — 못 불러온 공간에 "여기서 시작해보세요" 라고 하지 않습니다

같은 종류 중 **가장 나쁜 것**이 캔버스에 있었습니다.

공간을 불러오지 못하면 `loadCanvas` 에는 `catch` 가 없어서 메모가 빈 채로 남고, 화면은
**한 번도 글을 써 본 적 없는 사람에게 보여 주는 안내**를 띄웁니다.

```
여기 아무 곳이나 더블클릭 해보세요.
또는 아래에 생각을 바로 적어보세요.
```

생각이 천 개 있는 사람에게 **"이제 시작해보세요"** 라고 말한 것입니다. 위쪽에 오류 알림이
뜨긴 하지만, 그 알림보다 아래 초대문이 훨씬 크고 다정합니다.

## 이제

```
이 공간을 불러오지 못했습니다.
생각이 사라진 것이 아니라 가져오지 못한 것입니다.   [다시 시도]
```

**"비어 있다" 는 답이 도착했을 때만 할 수 있는 말입니다.** v0.53.5(로그인한 기기),
v0.53.10(Dream)과 같은 규칙이고, 여기서는 "비어 있다" 가 아니라 "아직 시작하지 않았다" 였기
때문에 더 나빴습니다.

## 검증

```
✘ 실패해도 시작 안내를 다시 표시  →  안내가 0개여야 하는데 1개, 시험 실패
```

## 시험 두 개가 같이 실패했던 일

캔버스 시험 두 개가 함께 실패해서 제 변경을 의심했습니다. **깨끗한 데이터베이스에서 다시
돌리니 25개 전부 통과**했습니다.

원인은 제가 계속 재사용한 e2e 데이터베이스였습니다. 시험이 쓰는 공간에 메모가 25개를 넘으면
캔버스가 **요약 보기**로 열리고, 메모가 개별 카드로 그려지지 않아 카드를 찾는 시험이
실패합니다. 어제 오프라인 큐 시험이 실패한 것과 **같은 이유**입니다.
