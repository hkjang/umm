# v0.66.3 — 아무도 듣지 못한 충돌

v0.66.1은 충돌한 변경을 다시 보내지 않기로 했습니다. 큐에 남기고, 사람의 결정을 기다립니다.
옳은 선택이지만, 그 결정을 **묻는 자리가 한 번뿐**이라는 것이 이번에 드러난 문제입니다.

```
    다른 공간을 보는 동안 충돌이 났습니다

            전                              후
    ━━━━━━━━━━━━━━━━━━━━━━      ━━━━━━━━━━━━━━━━━━━━━━
    409 버전 충돌                 409 버전 충돌
    umm:offline-conflict         umm:offline-conflict
    ↓                            ↓
    (듣는 화면이 없음)             (듣는 화면이 없음)
    ↓                            ↓
    영원히 큐에 남음               그 공간을 열면 다시 물음
    "1개 변경이 연결을             "1개 변경이 겹침 해결을
     기다리는 중"                   기다리는 중"  [겹침 확인]
    [지금 동기화] ← 눌러도
     아무 일도 없음
```

## 충돌은 한 번만 발생하고, 받는 화면은 하나입니다

`umm:offline-conflict`를 듣는 곳은 캔버스뿐이고, 그것도 **충돌한 메모가 지금 열어 둔
공간에 있을 때만** 대화상자를 엽니다. 그런데 큐를 비우는 flush는 배너에서 돌기 때문에 어느
화면에서든, 어느 공간에 대해서든 일어납니다.

- 캔버스가 닫혀 있었다면(검색·관리·설정 화면) — 아무도 듣지 못합니다
- 다른 공간을 보고 있었다면 — 이벤트를 받고도 그냥 버립니다
- 대화상자를 결정 없이 닫았다면(Esc·×) — 다시 여는 길이 없습니다

세 경우 모두 그 변경은 **영원히 큐에 앉습니다.** flush는 매번 건너뛰고, 배너는
`1개 변경이 연결을 기다리는 중`이라고 말합니다 — 연결은 되어 있는데도. `지금 동기화`를
아무리 눌러도 숫자는 줄지 않습니다.

## 붙잡아 둔 충돌은 다시 물을 수 있어야 합니다

이제 붙잡을 때 id만이 아니라 **이벤트 자체를 함께 보관합니다.** `replayOfflineConflicts()`가
그것을 그대로 다시 발생시킵니다 — 요청은 나가지 않습니다. 서버는 이미 답했고, 다시 물어도
같은 409이기 때문입니다. 이것은 서버가 아니라 **사람에게 다시 묻는 것**입니다.

다시 묻는 자리는 두 곳입니다.

- **공간을 열 때** — 그 공간에 대한 충돌이 붙잡혀 있으면 대화상자가 뜹니다. 공간 하나에만
  묶인 효과라, 대화상자를 닫으면 닫힌 채로 남습니다.
- **배너의 `겹침 확인`** — 언제든 사람이 직접 부릅니다.

한 번에 하나만 묻습니다. 결정하는 중에 두 번째 충돌이 화면에 끼어들면 비교 내용과 타이핑하던
병합문이 함께 사라지므로, 나머지는 붙잡힌 채로 순서를 기다립니다.

## 배너는 기다리는 것이 무엇인지 말합니다

연결을 기다리는 변경과 결정을 기다리는 변경은 다른 것입니다. 하나는 저절로 풀리고, 하나는
사람만 풀 수 있습니다.

| 상태 | 배너 |
| :--- | :--- |
| 오프라인 | `오프라인 · {n}개 변경을 안전하게 보관 중` |
| 온라인, 보낼 변경 | `{n}개 변경이 연결을 기다리는 중` · `지금 동기화` |
| 온라인, 붙잡힌 충돌 | `{n}개 변경이 겹침 해결을 기다리는 중` · `겹침 확인` |

`지금 동기화`는 실제로 보낼 것이 남아 있을 때만 나옵니다. 충돌뿐이라면 그 버튼은 아무것도
하지 않으므로, 없는 것이 정직합니다.

## 확인한 것

```
✓ 듣는 화면이 없을 때 난 충돌도 나중에 다시 물어짐
✓ 다시 묻는 것은 요청을 보내지 않음 (fetch 호출 1회 그대로)
✓ 결정한 변경은 붙잡음에서 빠져 다시 묻지 않음
✓ 배너가 결정 대기와 연결 대기를 다른 문장으로 말함
✓ 충돌만 남았을 때 `지금 동기화`는 나오지 않음
✓ 보낼 변경이 함께 있으면 두 버튼이 모두 나옴
✓ 결정 중인 충돌 위로 두 번째 충돌이 끼어들지 않음
```

| 바꾼 것 | 잡은 것 |
| :--- | :--- |
| 충돌 이벤트를 보관하고 다시 발생시킴 | 아무도 듣지 못해 영원히 갇힌 변경 |
| 공간을 열 때 · 배너 버튼으로 다시 물음 | 닫으면 다시 열 수 없던 병합 대화상자 |
| 결정 대기를 연결 대기와 나눠 표시 | 눌러도 아무 일 없는 `지금 동기화` |
