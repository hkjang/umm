# umm v0.18.0 — 멀리서 보면 무엇이 보이는가

노트가 수백 개가 되면 캔버스는 정보 창고가 아니라 정보 쓰레기장이 됩니다. 줌아웃해도 읽을 수 없는 사각형 수백 개가 보일 뿐입니다.

멀리서 볼 때는 **노트가 무엇으로 뭉치는지**가 보여야 합니다.

---

## 1. 두 단계입니다 (다섯이 아니라)

제안받은 안은 100% → 60% → 30% → 10% → 3%의 다섯 층이었습니다. **두 층으로 만들었습니다.**

다섯 층은 클러스터 위에 주제, 주제 위에 지식 섬이 있는 계층 구조를 전제합니다. umm에는 그 계층을 만들 데이터가 없습니다 — 군집은 있지만 군집의 군집은 없습니다. 없는 계층을 지어내면 **근거 없는 구조를 사실처럼** 보여 주게 됩니다.

| 줌 | 보이는 것 |
| :--- | :--- |
| 0.45 이상 | 개별 포스트잇 |
| 0.45 미만 | 뭉친 것들, 각각 개수와 이름 |

0.45는 기존 줌 범위(0.15~2.2)에서 **포스트잇 글자가 읽히지 않게 되는 지점**입니다.

### 요약할 것이 없으면 요약하지 않습니다

만들고 나서 바로 문제가 보였습니다. 노트 6개짜리 공간을 열면 `fitView`가 임계값 아래로 줌아웃하고, **캔버스가 스스로를 두 개의 덩어리로 요약해 버렸습니다.**

요약은 정보 과부하를 푸는 기능입니다. 과부하가 없는 캔버스에 적용하면 같은 것의 **더 나쁜 뷰**일 뿐입니다. 25개 미만이면 전환하지 않습니다.

---

## 2. 판단할 수 없으면 배치로 묶습니다

여기가 이번 릴리스에서 가장 중요한 결정입니다.

기존 군집은 임베딩 유사도로 묶습니다. 그런데 기본 임베딩은 **뜻이 아니라 겹치는 단어**를 재고(v0.10.0 측정: 쌍별 정확도 4.2%), 낮은 줌에서는 군집이 노트를 **대체**합니다. 어휘로 묶인 군집을 그렇게 보여 주면 워크스페이스에 대해 **자신 있게 틀린 그림**을 주게 됩니다.

대안은 "아무것도 안 함"이 아닙니다.

**umm은 공간 도구이고, 노트가 어디 있는지는 사람이 결정한 데이터입니다.** 가까이 놓은 것끼리 묶으면 지어낸 구조가 아니라 **실재하는 구조**를 보고하게 됩니다.

| 백엔드 | 묶는 기준 | 화면 |
| :--- | :--- | :--- |
| 의미를 판별함 | 내용 | 실선 테두리 · "내용으로 묶임" |
| 판별하지 못함 | 배치 | 점선 테두리 · "가까이 둔 것으로 묶임" |

같은 모양으로 보여 주지 않습니다. **다른 주장이기 때문입니다.**

배치 군집은 단일 연결(single-link)입니다 — 한 멤버와 가까우면 합류합니다. 생각을 한 줄로 늘어놓은 것은 쌍의 사슬이 아니라 하나의 흐름이고, 사람들은 실제로 그렇게 배치합니다.

거리 기준(120px)은 절대값이고 그래도 됩니다. 유사도와 달리 **캔버스에는 사람이 작업하는 고정된 척도**가 있습니다 — 기본 노트가 260×180이므로 "노트 반 개쯤 떨어진 거리"는 어느 워크스페이스에서나 같은 뜻입니다.

---

## 3. 레이아웃을 다시 배치하지 않습니다

덩어리는 **멤버들이 차지한 땅을 그대로 덮습니다.** 줌아웃했다고 캔버스가 스스로 재배치되면, 사람이 만든 배치 — umm에서 가장 중요한 사용자 데이터 — 를 잃어버립니다.

어느 덩어리에도 속하지 않은 노트는 **그대로 남습니다.** 그것들이 바로 눈에 띄어야 할 예외이고, 숨기면 워크스페이스가 실제보다 정돈된 것처럼 보이게 됩니다.

---

## 4. 그 밖에 실제로 돌려 보고 고친 것

**라벨이 안 보였습니다.** 이 뷰는 0.45 줌 아래에서만 나타나므로 글자 크기가 화면 픽셀이 아니라 **캔버스 단위**여야 했습니다. 104px로 쓴 숫자가 0.25 줌에서 26px로 그려집니다.

---

## 업그레이드

스키마 변경이 없습니다. 이미지만 교체하면 됩니다.

```bash
docker run -d --name umm --restart unless-stopped \
  -p 8080:8080 \
  -e POSTGRES_DSN='postgres://umm:password@postgres.internal:5432/umm?sslmode=require' \
  -e BOOTSTRAP_ADMIN='admin' \
  -e BOOTSTRAP_ADMIN_PASSWORD='your-strong-password' \
  -e ENCRYPTION_KEY='your-32-char-random-encryption-key' \
  umm:v0.18.0
```

- `GET /spaces/{id}/clusters` 응답에 `basis`가 추가됐습니다(`meaning` 또는 `proximity`). 기존 필드는 그대로입니다.
- 임베딩 모델을 설정하지 않은 배포에서는 군집이 **배치 기준으로 바뀝니다.** 이전에는 어휘 기준이었고, 그것을 "내용으로 묶었다"고 제시하고 있었습니다.
