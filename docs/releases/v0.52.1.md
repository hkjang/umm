# v0.52.1 — 질문은 질문으로 돌아옵니다

되살리기의 마지막 구멍입니다. 내보내기는 처음부터 이렇게 적고 있었습니다.

```
- type: `question`
```

그런데 가져오기는 **무조건 `thought` 로** 만들었습니다. 질문으로 표시해 둔 생각이 평범한
생각으로 돌아왔습니다. 굳이 따로 표시해 둔 이유가 바로 그 구분인데요.

이제 내보낸 그대로 돌아옵니다 — `question` 은 `question` 으로, `idea` 는 `idea` 로.

## 그리고 다음에 같은 일이 생기지 않도록

이걸 고치면서 **조용한 함정** 하나를 발견했습니다.

가져오기는 본문에서 메타데이터를 떼어낼 때 **정해진 이름 목록**만 봅니다 —
`id`·`type`·`source`·`canvas`·`line`. 내보내기에 새 항목을 하나라도 추가하면, 가져오기는
그걸 메타데이터로 알아보지 못하고 **본문에 그대로 남깁니다.** 되살린 생각마다 아무도 쓰지
않은 줄이 한 줄씩 붙는 것입니다.

기존 계약 시험은 "쓰던 항목이 사라졌는지"만 봤습니다. **늘어난 경우는 통과했습니다.**

이제 양쪽 다 봅니다. 내보내기가 가져오기가 모르는 항목을 쓰면 Go 쪽에서 파일 이름까지
짚어서 실패합니다.

```
내보내기에 `- colour: \`yellow\`` 를 추가해 봄
  → the export writes "colour", which web/src/lib/markdown-import.ts does not strip;
    a restored thought would carry it in its body
```

## 검증

```
✘ 가져올 때 kind 를 무시  →  "question" 자리에 "thought" 가 나와 실패
✘ 내보내기에 모르는 항목 추가  →  Go 계약 시험이 항목 이름과 고칠 파일을 짚어 실패
```

되돌리기는 **빌드가 실제로 성공하고 번들 파일 이름이 바뀐 것을 확인한 뒤에** 믿었습니다.
