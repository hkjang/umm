# v0.23.0 — 살펴보고 답하는 조력자

한 번의 검색으로 답하던 것을, **찾아보고 → 읽고 → 필요하면 다시 찾아본 뒤** 답하도록 바꿨습니다.
사람이 자기 기록을 뒤질 때 하는 일과 같습니다.

## 무엇이 달라지나

`오늘` 화면의 "내 기억에 물어보기"에 **살펴보고 답하기** 모드가 생겼습니다.

기존 `한 번에 답하기`는 그대로입니다. 질문 하나에 검색 한 번, 근거를 인용해 답합니다.
`살펴보고 답하기`는 조력자가 스스로 무엇을 더 봐야 할지 정합니다.

실제 동작(로컬 모델 `qwen3.6`, 실측):

```
질문: 아직 답하지 못한 질문이 뭐가 있는지 확인하고, 관련된 생각이 있으면 같이 알려줘

  1. 열린 질문을 확인함 — 열린 질문 1개
  2. 생각을 검색함 {"query":"온보딩 문서"} — "온보딩 문서"에 대해 1개 찾음

답: 아직 답하지 못한 질문은 "온보딩 문서를 다시 쓸지 아직 결정하지 못했다"입니다. …
```

두 번째 검색어 `온보딩 문서`는 아무도 알려 주지 않았습니다. 첫 조회 결과를 읽고 조력자가 정했습니다.
이것이 한 번에 답하기와의 차이입니다.

## 읽기만 합니다 — 플래그가 아니라 구조로

조력자가 부를 수 있는 도구는 **셋뿐이고 전부 조회**입니다.

| 도구 | 하는 일 |
| --- | --- |
| `search_thoughts` | 생각 검색 + 연결 한 걸음 (`/ai/ask`와 같은 경로) |
| `find_open_questions` | **열린 것으로 표시된** 질문 |
| `find_contradictions` | **상충으로 표시된** 쌍 |

만들기·고치기·연결하기·합치기·지우기 도구는 **아예 붙어 있지 않습니다.** 권한 플래그를 확인해서 막는 게
아니라, 모델이 부르고 싶어도 **부를 것이 없습니다.** 경계가 런타임 검사가 아니라 도구 목록 그 자체입니다.

제안은 텍스트로 돌아오고, 실행은 사람이 합니다.

테스트가 그 경계를 지킵니다. 도구 이름에 `create·update·delete·merge·connect·move·write`가 들어가면
단위 테스트가 실패하고, 통합 테스트는 **게이트웨이로 실제 전송된 JSON**의 도구 목록을 검사합니다 —
Go 코드가 아니라 모델이 실제로 받은 것을 봅니다.

## 무엇을 봤는지 보여 줍니다

답과 함께 조회 과정이 순서대로 나옵니다. 살펴본 끝에 나온 답이 추측보다 나은 이유는 **어디를 봤는지
확인할 수 있기 때문**이고, 그러려면 보여 줘야 합니다.

## AI 제외는 도구를 통해서도 새지 않습니다

`/ai/ask`와 같은 조회 경로를 쓰므로 노트·공간·연결 세 경로 모두 그대로 막힙니다.

실측으로 확인했습니다. `인증 토큰 만료는 24시간` 노트를 AI 제외로 표시한 뒤:

```
1. "인증 토큰 만료" — 0개    2. "토큰" — 0개
3. "만료" — 0개              4. "인증" — 0개

답: 인증 토큰 만료 기간에 대한 정보는 현재 생각 공간에 기록되어 있지 않습니다.
제외됨: 4
```

네 번 다르게 시도했고 네 번 다 막혔습니다. 그리고 `제외됨: 4`가 **무언가 빠졌다는 사실 자체는**
사람에게 보입니다 — 답이 완전한 것처럼 읽히지 않도록.

## 끝나지 않는 것을 막았습니다

한 번 실행은 조회 **6번**까지입니다. 한도에 닿으면 **도구 없이** 한 번 더 물어봅니다. 지금까지 확인한
것이라도 남기되, `truncated`로 **결론이 아니라 중간에 끊긴 것**임을 표시합니다.

도구를 쥐여 준 채 "그만 찾고 답하라"고 말하는 것은 그만두라는 말이 아닙니다 — 모델은 도구를 한 번 더
부르고, 사람은 빈 답을 받습니다. 만들면서 실제로 그랬고, 테스트가 잡았습니다.

## 비용은 요청한 사람이 냅니다

한 턴은 모델 호출 하나이고 그 사람의 **일일 할당량에서** 차감됩니다.

이것도 만들면서 틀렸습니다. 할당량을 사람이 아닌 빈 사용자에게 차감하고 있었고, 빈 사용자는 할당량을
**건너뜁니다** — 한 요청에 공짜 모델 호출 6번. 주석에는 "공짜가 아니게 만든다"고 쓰여 있었습니다.
지키지 못하는 보장을 적어 둔 주석이 가장 나쁜 종류입니다. 회귀 테스트가 이제 실제 차감 건수를 셉니다.

## API

```
POST /api/v1/ai/agent   { "task": "..." }
→ { "answer", "steps": [{tool, input, summary}], "excluded", "model", "truncated" }
```

`ai:assist` 스코프. 채팅 모델이 없으면 `412`(관리자가 1분이면 고칠 수 있는 문제라 `502`와 구분합니다).
