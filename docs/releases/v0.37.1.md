# v0.37.1 — 한국어에서 1px 차이로 안 보이던 것

어제 붙인 배지가 **영어에서 카드 밖으로 튀어나오고 있었습니다.**

가장 작은 메모(190px)에 표시 세 개가 모두 붙은 경우입니다.

| | 한국어 | 영어 |
| --- | ---: | ---: |
| 배지 줄 실제 너비 | 139px | **207px** |
| 들어갈 수 있는 너비 | 138px | 138px |
| 카드 밖으로 나간 거리 | 0px | **68px** |

한국어는 **138 대 139, 1px 차이로 간신히 맞았습니다.** 그래서 개발하는 언어에서는
아무 문제가 없어 보였습니다. 영어에서는 `Not analysed` 배지가 카드를 68px 벗어나 메모 메뉴
버튼 위에 얹혔습니다.

배지 줄이 **카드 위에 절대 위치로 얹혀 있고 줄바꿈을 못 했기 때문**입니다. `max-width`는
줄의 상자만 제한할 뿐, 그 안의 배지가 밖으로 나가는 것은 막지 못합니다.

## 카드를 세로 흐름으로 바꿨습니다

이제 카드가 열(column)입니다. 글 위에 있는 것은 글을 **덮는 대신 아래로 밀어냅니다.**
배지는 자리가 모자라면 다음 줄로 접힙니다.

바꾸고 나니 **DOM 순서가 드러났습니다.** 배지 블록이 `textarea` 뒤에 있었는데, 절대 위치일
때는 상관없던 것이 흐름에 들어가자 **배지가 글 아래로 내려갔습니다.** 화면을 보고 알았습니다 —
숫자만 봤다면 "카드 안에 있음"으로 통과했을 겁니다.

## 이 조합만 드러냅니다

이 결함은 **영어 + 가장 작은 크기 + 표시 세 개**가 동시에 있어야 보입니다. 셋 중 하나만
빠져도 멀쩡해 보입니다. 그래서 새 테스트는 그 조합을 고집합니다.

배지 위치는 줄의 상자가 아니라 **배지 자체의 좌표**로 잽니다. `max-width`에 걸린 줄은 안에
있는 배지가 밖으로 나가 있어도 "맞는다"고 측정되기 때문입니다.

되돌려서 확인했습니다: v0.37.0 배치에서 배지 오른쪽 끝 `1107px`, 카드 오른쪽 끝 `1048px`.
