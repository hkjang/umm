# v0.53.9 — 자기 요청을 자기가 승인하라고 권하지 않습니다

`검토 · 승인` 화면은 **팀장에게 자기 요청의 `승인`·`반려` 버튼을 보여 줬습니다.**

목록에 자기 요청이 보이는 것은 **의도한 것**입니다 — 내가 올린 요청이 어떻게 되고 있는지
봐야 하니까요. 문제는 거기에 결재 버튼까지 달려 있었다는 것입니다.

서버 규칙은 분명합니다.

```
자신의 요청 또는 다른 팀의 요청은 검토할 수 없습니다.   (403)
```

즉 팀장이 자기 요청의 `승인`을 누르면 **거절당합니다.** 되지 않을 일을 권하는 버튼인데,
하필 **결재 화면**입니다.

## 이제

화면이 서버와 **같은 규칙**을 씁니다 — 더 느슨하지도, 더 빡빡하지도 않게.

```
관리자          모든 대기 요청
팀장            같은 팀 · 내가 올린 것이 아닌 요청만
그 외           결재 버튼 없음
```

느슨하면 눌렀다 거절당하고, 빡빡하면 할 수 있는 일을 못 하게 됩니다. 둘 다 사람이 해석해야
하는 문제라, 규칙을 그대로 옮겼습니다.

## 필요한 정보는 이미 서버가 보내고 있었습니다

`requesterId` 와 `teamId` 는 처음부터 응답에 들어 있었고, **화면 쪽 타입 선언에만
빠져 있었습니다.** 새로 받아 올 것이 없었습니다.

## 검증

```
✘ 팀장이 무엇이든 결재 가능 (= 이전 동작)  →  버튼이 1개여야 하는데 3개, 시험 실패
```

시험은 세 가지를 한 화면에 놓습니다 — 내가 올린 것, 같은 팀 동료가 올린 것, 다른 팀 것.
**결재할 수 있는 것은 하나뿐**이고, 나머지 둘도 목록에는 그대로 보입니다.
