그래서 남은 문을 마저 세어 봤습니다. **검색**이 있었습니다.

## 생각을 가장 자주 만나는 자리

`Ctrl+K` 빠른 이동에서 "젠킨스"를 치면 이렇게 나왔습니다.

```
젠킨스 플러그인 호환 문제를 우리가 매번 떠안게 된다      통합 확인 · 본문 일치   99%
배포 파이프라인을 젠킨스로 직접 운영하면…               통합 확인 · 본문 일치   66%
배포 파이프라인을 젠킨스로 직접 운영하면…               통합 확인 · 본문 일치   99%
```

세 개가 똑같이 생겼습니다. 그중 둘은 **검토한 뒤 하지 않기로 한 갈래**에 있습니다.

지금은:

```
젠킨스 플러그인 호환 문제를 우리가 매번 떠안게 된다
  통합 확인 · 접어 둔 갈래: 젠킨스 직접 운영            [접어 둠]

배포 파이프라인을 젠킨스로 직접 운영하면…
  통합 확인 · 본문 일치                                  66%      ← 지금 쓴 것

배포 파이프라인을 젠킨스로 직접 운영하면…
  통합 확인 · 접어 둔 갈래: 젠킨스 직접 운영            [접어 둠]
```

가운데가 나중에 쓴 쪽이고 갈래에 없습니다. **어느 쪽이 거절된 버전인지 보입니다.**

## 진행 중인 갈래는 표시하지 않습니다

진행 중이거나 채택한 갈래는 생각의 평범한 상태입니다. 결과마다 딱지를 붙이면 경고가 아니라
벽지가 됩니다.

## 같은 규칙을 네 번 따로 구현하지 않도록

`BranchRefsForNotes`를 store에서 공개로 올렸습니다. **생각이 나타나는 모든 자리**가 "이 갈래는
접어 둔 것"이라고 말할 수 있어야 하는데, 그때마다 조회를 새로 짜면 다음 문에서 또 빠뜨립니다.

## 확인한 것

- 전체 Go 테스트 통과, 웹 53개 통과, 타입·린트·i18n 통과
- 갈래에 속하지 않은 결과에는 딱지가 붙지 않는지 통합 테스트로 고정
- 이유가 딱지와 함께 오는지 고정
- **브라우저에서 실제로 확인**: 같은 검색어에 접어 둔 둘과 지금 쓴 하나가 구분되어 나옵니다
