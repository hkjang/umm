# v0.33.1 — 읽어 주는 사람에게는 접어 둔 갈래가 없었습니다

캔버스에서 접어 둔 갈래의 생각에는 `접어 둠` 배지가 붙습니다. 그런데 그 배지는 `<span>`이고,
어느 갈래인지는 **마우스를 올려야** 나오는 툴팁에 있습니다.

메모 카드의 이름은 이랬습니다.

```
생각 메모: 배포 파이프라인을 젠킨스로 직접 운영하면 통제권을 가져올 수 있다
```

화면 낭독기로 이 카드를 읽는 사람에게는 **현재 생각과 구별되지 않습니다.**

갈래가 막으려는 일이 정확히 그것입니다 — 이미 거절한 선택지를 현재 방침으로 착각하는 것.

## 지금은

접어 둔 갈래에 속하면 이름에 함께 들어갑니다.

```
생각 메모: 배포 파이프라인을 젠킨스로… · 접어 둔 갈래: 젠킨스 직접 운영
```

배지는 그대로 있습니다. 눈으로 보는 사람에게는 배지가, 읽어 주는 사람에게는 이름이 같은 말을
합니다.

## e2e가 이름을 확인합니다

`toHaveAccessibleName`으로 갈래 이름이 카드 이름에 들어 있는지 봅니다. 배지가 보이는지만 보면,
**보이는 것과 읽히는 것이 갈라져도 통과합니다.**

## 확인하다 실수한 것

처음 돌렸을 때 실패했습니다. 코드가 아니라 **검증 절차**가 틀렸습니다 — 웹 번들을 다시 만들지 않고
Go 바이너리만 빌드해서, 예전 번들이 그대로 박혀 있었습니다. 바이너리에서 새 문자열을 찾아 보고
알았습니다.

## 확인한 것

- e2e 19개 통과 (접근 가능한 이름 확인 포함)
- 전체 Go 테스트 통과, 타입·린트·i18n 통과
