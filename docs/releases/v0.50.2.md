# v0.50.2 — umm이 내보낸 파일을 umm이 다시 읽습니다

내보내기와 가져오기는 둘 다 umm 의 기능인데, **서로 맞춰 본 적이 한 번도 없었습니다.**

공간을 마크다운으로 내보내고 그 파일을 그대로 가져오면 이렇게 됐습니다.

```
생각 3개를 내보냄  →  가져오니 5개

  "돌아오는 공간"        Exported from umm at 2026-08-26T16:01:02+09:00.   ← 머리말이 생각이 됨
  "Thought"             이어진 생각의 본문
                        - id: `bfe3a64a-…`                                ← 본문에 딸려 들어옴
                        - type: `thought`
                        - canvas: `0, 0`
  "Thought"             제목이 없는 생각의 본문                             ← 제목이 전부 "Thought"
  "Connections"         - `f254…` --related--> `bfe3…`                    ← 연결 목록도 생각이 됨
  "Lines of thinking"   - **되돌리기 실험** — adopted: 되돌아왔습니다
```

**되돌릴 수 없는 백업은 백업이 아닙니다.**

## 이제

```
생각 3개를 내보냄  →  가져오니 3개

  (제목 없음)            이어진 생각의 본문
  "제목이 있는 생각"      제목이 있는 생각의 본문
  (제목 없음)            제목이 없는 생각의 본문
```

머리말은 건너뜁니다. `id`·`type`·`source`·`canvas`·`line` 목록은 본문에서 떼어냅니다.
`Connections` 와 `Lines of thinking` 는 공간에 **대한** 설명이지 그 안의 생각이 아니므로
가져오지 않습니다. `Thought` 는 제목 없는 메모에 내보내기가 붙이는 말이므로, 되돌릴 때
제목으로 되살리지 않습니다.

## 남의 마크다운은 건드리지 않았습니다

위 규칙은 **umm 이 만든 파일을 umm 의 파일로 읽는 것**입니다. 다른 사람의 노트가 같은 단어를
쓸 수 있고, 거기엔 하나도 적용되면 안 됩니다.

그래서 문서가 스스로 내보내기임을 밝힐 때만 — 공간 이름 바로 아래 `Exported from umm at`
줄이 있을 때만 — 적용합니다. 그 밖의 마크다운은 예전과 **글자 그대로 똑같이** 읽습니다.

```
# Connections           →  제목 "Connections" 그대로
## Thought              →  제목 "Thought" 그대로
- id: `내 번호`          →  본문에 그대로 남음
```

본문 한참 아래에서 `"Exported from umm at"` 을 인용한 문서도 내보내기로 오해하지 않습니다.

## 검증

네 가지 규칙을 하나씩 되돌려서, **되돌린 코드가 실제로 돌아가는지 확인한 뒤** 결과가
달라지는 것을 봤습니다.

```
✘ 머리말 건너뛰기 제거      →  3개가 4개로 (머리말이 생각이 됨)
✘ 구역 건너뛰기 제거        →  3개가 5개로 (Connections·Lines of thinking 이 생각이 됨)
✘ 메타데이터 떼기 제거      →  본문마다 id·type·source·canvas 가 붙음
✘ "Thought" 처리 제거      →  제목이 다시 "Thought"
```

가져오기 전체를 v0.50.1 상태로 되돌리면 새 시험 6개가 실패하고, 안전장치 시험 2개
(`평범한 문서는 예전 그대로`, `문구를 인용한 문서를 오해하지 않음`)는 **양쪽 모두에서
통과**합니다 — "달라지지 않았다" 는 주장은 그렇게 생겨야 맞습니다.

시험에 쓰는 내보내기 파일은 지어낸 것이 아니라 **내보내기가 실제로 만든 출력**입니다.
그리고 반대쪽에도 시험을 하나 뒀습니다. 내보내기가 머리말·메타데이터 이름·구역 제목·
`Thought` 중 무엇이라도 바꾸면 Go 쪽에서 먼저 실패합니다 — 누군가의 복원된 공간에서
조용히 어긋나는 대신에요.

```
내보내기의 "Thought" 를 "Note" 로 바꿔 봄
  → an untitled thought no longer exports as `## Thought` 로 실패
```
