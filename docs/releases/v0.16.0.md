# umm v0.16.0 — 지난밤 요약

아침에 들어왔을 때 밤사이 무엇이 쌓였는지 한눈에 보이는 카드입니다.

---

## 1. 없는 것은 세지 않습니다

제안받은 목업에는 `모순 3`, `중복 생각 5`, `중요도가 상승한 생각 2` 같은 줄이 있었습니다. **그중 둘은 umm이 탐지하지 못합니다.**

세지 않은 항목 옆의 `0`은 "없다"로 읽힙니다. "아무도 안 봤다"로 읽히지 않습니다. 그래서 브리핑은 **umm이 실제로 만들어 낸 것만** 셉니다.

| 항목 | 근거 |
| :--- | :--- |
| 읽지 않은 Dream | `dream_notes` (타입별) |
| 검토 대기 중인 추천 연결 | `origin='auto'` 엣지 |
| 아직 정리하지 않은 생각 | 수집함의 메모 |
| 겹쳐 보이는 생각 | 새로 만든 중복 탐지 |

모순은 항목 자체가 없습니다. 만들지 않은 기능을 자리로 광고하지 않습니다.

### 확인하지 못한 것도 말합니다

빈 목록은 백엔드에 따라 **다른 뜻**입니다. 그래서 응답에 `skipped`가 있습니다.

```json
{"duplicates": [], "skipped": [{"kind":"duplicates","reason":"backend-not-semantic"}], "quiet": false}
```

`quiet`는 **보고할 것이 없고 동시에 건너뛴 것도 없을 때만** 참입니다. 조용한 아침과 들여다보지 않은 아침이 같아 보이면 안 됩니다.

---

## 2. 중복 탐지, 그리고 절대값을 쓴 이유

v0.9.0 이후 umm의 모든 유사도 판정은 **분포 상대 기준**입니다. 백엔드마다 "가깝다"의 숫자가 완전히 달라서였습니다.

중복 판정은 **예외로 코사인 절대값을 씁니다.** 짐작이 아니라 재고 정했습니다.

| | 거의 같은 글 | 패러프레이즈 | 관련 | 무관 |
| :--- | ---: | ---: | ---: | ---: |
| bge-m3 | **0.943–0.983** | 0.596–0.668 | 0.533–0.681 | 0.312–0.348 |
| paraphrase-multilingual | **0.954–0.986** | 0.523–0.536 | 0.503–0.581 | 0.038–0.133 |

거의 같은 글은 **어떤 임베딩에서도 맨 위**에 오고, 두 모델이 사실상 같은 지점에 둡니다. 그다음 등급과의 간격이 0.26~0.37로 넓습니다. 하나의 숫자가 양쪽에서 통합니다.

상대 기준이 오히려 **여기서는 틀립니다.** 중복이 많은 공간은 자기 분포가 올라가서, 중복이 가장 많을 때 중복이 유난해 보이지 않게 됩니다.

기본값 0.92는 관리자 화면에서 조절할 수 있고, 0.7 미만으로는 내려가지 않습니다.

### 내장 임베딩으로는 하지 않습니다

내장 문자 n-gram도 재 봤습니다.

```
거의 같은 글  0.505 – 0.889
어휘 함정     0.449 – 0.572
```

**범위가 겹칩니다.** 진짜 중복이 어휘 함정보다 낮게 나올 수 있습니다. 그래서 다른 의미 기능과 같은 관문을 씁니다 — 판별하지 못하는 백엔드에서는 찾지 않고, 찾지 않았다고 말합니다.

---

## 3. 만들면서 고친 것

브리핑 테스트가 기본 백엔드를 **가정**하고 있었습니다. `app_settings`의 `ai_gateway`는 전역 행 하나라, 앞서 제가 직접 게이트웨이를 설정해 둔 상태에서 테스트가 돌자 "판별 가능한 백엔드"를 만나 실패했습니다.

이번 작업에서 세 번째로 만난 같은 종류의 문제라, 이번에는 **백엔드를 입력으로 만드는 헬퍼**를 넣었습니다. 오프라인 경로를 검증하려는 테스트는 설정을 지우고, 실제로 오프라인이 아니면 큰 소리로 실패합니다.

## 업그레이드

**마이그레이션이 있습니다** (014). 기존 설정 행에 중복 임계값만 채웁니다. 동작은 바뀌지 않습니다.

```bash
docker run -d --name umm --restart unless-stopped \
  -p 8080:8080 \
  -e POSTGRES_DSN='postgres://umm:password@postgres.internal:5432/umm?sslmode=require' \
  -e BOOTSTRAP_ADMIN='admin' \
  -e BOOTSTRAP_ADMIN_PASSWORD='your-strong-password' \
  -e ENCRYPTION_KEY='your-32-char-random-encryption-key' \
  umm:v0.16.0
```

- 임베딩 모델을 설정하지 않은 배포에서는 브리핑이 **중복을 확인하지 않았다고 표시합니다.** 의도된 동작입니다.
- `GET /api/v1/morning-brief?hours=168`로 기간을 바꿀 수 있습니다. 일주일 만에 돌아왔다면 일주일을 봐야 합니다.
