# v0.28.1 — 갈래가 내보내기에서 사라지고 있었습니다

umm의 내보내기 코드에는 이런 주석이 있습니다.

> An export is what someone keeps when umm is gone.
> (내보내기는 umm이 사라졌을 때 그 사람에게 남는 것입니다.)

그래서 연결에는 **누가 그었는지**(`origin`)가 붙어 있습니다. 사람이 그은 선과 소프트웨어가 만든
선이 종이 위에서 구분되지 않으면 안 되니까요.

**갈래는 붙어 있지 않았습니다.**

## 무엇이 사라지고 있었나

v0.24.0에서 갈래를, v0.26.0에서 결정을, v0.27.0에서 되짚기를 만들었습니다. 그런데 내보내기는
생각과 연결만 실어 갔습니다.

- 어떤 생각이 **어느 갈래에 속했는지** — 사라짐
- 그 갈래를 **접어 두기로 했다는 사실** — 사라짐
- **왜 접어 뒀는지** — 사라짐

가장 나쁜 건 세 번째입니다. **이유는 사람들이 가장 먼저 잃는 절반이고**, 자기 기록을 다른 곳으로
가져가는 순간은 그걸 잃기에 가장 나쁜 때입니다.

## 지금은

각 생각 블록에:

```
## Thought

배포 파이프라인을 젠킨스로 직접 운영하면 통제권을 가져올 수 있다

- id: `…`
- type: `thought`
- source: `user`
- canvas: `0, 0`
- line: `젠킨스 직접 운영` (abandoned)
```

그리고 문서 끝에:

```
## Lines of thinking

- **젠킨스 직접 운영** — abandoned: 플러그인 호환 부담이 통제권으로 얻는 것보다 컸습니다
```

갈래에 속하지 않은 생각에는 아무것도 붙지 않습니다. 테스트가 그것도 지킵니다 — 없는 소속을
지어내면 안 되니까요.

## 확인한 것

- 전체 Go 테스트 통과, 웹 53개 통과
- 실제 세션으로 라우터를 통과시켜 검증 — 핸들러를 직접 부르지 않고, 사람이 받는 파일 그대로
- 실행 중인 인스턴스에서 실제 내보내기 파일 확인
- 갈래 없는 생각에 `- line:`이 붙지 않는지 고정
