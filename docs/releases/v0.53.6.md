# v0.53.6 — 댓글 메뉴도 할 수 있는 것만 보여 줍니다

v0.49.0 에서 읽기 전용 공간의 **캡처 바**와 **메모 메뉴**를 정리했습니다. **댓글 메뉴는
빠져 있었습니다.**

댓글 메뉴는 누구에게나 `해결 표시`·`다시 열기`·`삭제` 를 전부 보여 줬습니다. 서버 규칙은
그렇지 않습니다.

```
해결·재개   공간 주인이거나 edit·manage 권한
삭제        댓글 쓴 사람, 또는 공간 주인·manage
```

읽기로 초대받은 사람은 남의 댓글에 `해결 표시` 와 `삭제` 를 눌러 보고 **거절당하고 나서야**
알게 됐습니다. 되지 않을 일을 권하는 버튼입니다.

## 이제

- `해결 표시`·`다시 열기` 는 편집 권한 이상일 때만 나옵니다
- `삭제` 는 **자기가 쓴 댓글**이거나 공간을 관리할 때만 나옵니다
- 둘 다 아니면 메뉴 자체가 나오지 않습니다

읽기 권한이어도 **자기 댓글은 자기가 지웁니다.** 그건 권한과 상관없이 늘 그랬습니다.

## 검증

```
✘ 해결을 다시 모두에게 노출  →  읽기 전용 화면에 `해결 표시` 가 나타나 시험 실패
```

되돌리기가 **빌드에 성공하고 번들이 실제로 바뀐 것**을 확인한 뒤에 믿었습니다.

## 시험을 처음엔 잘못 썼습니다

"읽기 전용이면 댓글 메뉴가 아예 없어야 한다" 고 적었다가 실패했습니다. 그 댓글은 **로그인한
본인이 쓴 것**이었고, 권한을 view 로 흉내 냈다고 해서 글쓴이가 바뀌지는 않습니다. 자기 댓글의
`삭제` 는 나오는 게 **맞습니다.**

고친 쪽이 틀린 게 아니라 제 단정이 틀렸습니다. 이제 의미 있는 구분을 봅니다 — `삭제` 는 있고
`해결 표시` 는 없다.
