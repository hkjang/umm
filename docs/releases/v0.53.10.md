# v0.53.10 — 못 불러왔으면서 "아직 없어요" 라고 하지 않습니다

Dream 목록을 불러오지 못하면 화면에 **두 가지가 동시에** 떴습니다.

```
[빨간 알림]  Dream을 불러오지 못했습니다.

[큰 카드]    검토할 Dream이 없어요
             충분한 생각이 쌓이면 근거와 함께 새로운 관점이 이곳에 도착합니다.
             [Dream 설정 보기]
```

아래쪽이 **더 크고, 더 친절하고, 틀렸습니다.** 그리고 사람이 믿는 쪽도 아래쪽입니다 —
"아, 아직 없구나" 하고 설정을 보러 갑니다. 실제로는 있는데 못 가져온 것뿐인데요.

v0.53.5 의 `로그인한 기기` 와 같은 종류입니다. 그쪽은 오류조차 없었고, 이쪽은 오류를 띄운
뒤 **바로 밑에서 반박**합니다.

## 이제

- 불러오지 못했으면 **"없어요" 카드를 띄우지 않습니다**
- 알림에 `다시 시도` 를 붙였습니다

**"아직 없다" 는 답이 도착했을 때만 할 수 있는 말입니다.**

## 검증

```
✘ 오류와 함께 "없어요" 카드 복원  →  카드가 0개여야 하는데 1개, 시험 실패
```

---

**전체 검증**: dreams e2e 4개 · `tsc -b` · oxlint · Prettier · i18n 850키 · 버전 일관성

**함께 확인한 것(고칠 것 없음)**: 관리자 설정의 비밀값은 `ai_gateway.api_key`,
`oidc.client_secret`, `ptium.api_key` 셋이고 **모두 가려집니다.** 나머지 항목은 주소와
숫자입니다. 역할 검사(`admin` 전용 화면들)도 서버 규칙과 어긋나는 곳이 없었습니다.
