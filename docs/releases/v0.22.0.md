# umm v0.22.0 — 내 기억에 물어보기

Thought Agent의 첫 두 단계(Observe → Search)입니다. 그리고 **답을 근거 있게 만들 수 있는지를 결정하는** 절반이기도 합니다.

---

## 1. 자율성 범위는 문서에 답이 있었습니다

지난번에 "에이전트의 자율성 범위는 제품 결정이라 단독으로 정하기 어렵다"고 말씀드렸는데, 보내주신 다이어그램에 이미 답이 있었습니다.

```
Observe → Search → Traverse → Reason → Suggest → 사용자 승인 → Create/Link/Merge
```

**읽기는 자유, 쓰기는 승인.** 이번 릴리스는 그 왼쪽 절반이고, **아무것도 쓰지 않습니다.**

---

## 2. 검색이 아니라 검색 + 한 걸음

질문의 답은 그 질문을 던진 생각 *안*이 아니라 **옆**에 적혀 있는 경우가 많습니다. 그래서 검색한 뒤 그래프를 한 걸음 따라갑니다.

실측입니다. `24시간이면 충분하다고 결론 내렸다`는 질문 `인증 토큰 만료를 얼마로 정했나`와 **단어를 하나도 공유하지 않습니다.** 연결로만 도달할 수 있습니다.

```
질문: 인증 토큰 만료를 얼마로 정했나

답: 인증 토큰 만료 시간은 24시간으로 정했습니다. [2]

  [1] 질문과 일치       인증 토큰 만료 시간을 몇으로 둘까
  [2] 연결을 따라 도달   24시간이면 충분하다고 결론 내렸다
```

---

## 3. 근거 없는 답을 만들지 않습니다

**답은 사용자가 직접 적어 둔 생각만으로 만들어지고, 어느 것을 썼는지 `[번호]`로 표시합니다.** 근거 없는 주장은 인용이 없다는 사실로 드러납니다.

검색 결과가 없으면 **모델을 아예 호출하지 않습니다.** 근거가 없는 답이 가장 그럴듯하고 가장 틀리는 경우가 바로 그때이고, 그래도 물어보면 그런 답을 얻게 됩니다.

```json
{"grounded": false, "answer": ""}
```

화면에는 이렇게 나옵니다.

> 이 질문에 답할 만한 생각을 찾지 못했습니다. 지어내지 않고 그대로 말씀드립니다.

---

## 4. AI 제외가 가장 중요했습니다

여기서 나가는 모든 것은 게이트웨이로 갑니다. 그리고 **umm은 이 결함을 실제로 낸 적이 있습니다** — v0.8.0에서 내용을 캡처한 뒤에 제외 플래그를 확인하는 경로가 있었습니다.

검색 계층은 그게 잊히기 딱 좋은 자리라, 테스트 다섯 개 중 셋이 이것입니다.

| | |
| :--- | :--- |
| 노트 단위 제외 | 검색 결과에서 빠집니다 |
| **공간 단위 제외** | 노트만 확인하면 그 공간 전체가 샙니다 |
| **연결을 통한 우회** | 검색에서 막고 이웃 탐색에서 끌어오면 더 긴 경로로 같은 유출입니다 |

제외된 것은 조용히 빼지 않고 **개수를 보고합니다.** 기대보다 적은 자료로 만든 답이 완전한 답처럼 보이면 안 되는데, 내용을 드러내지 않고 알릴 방법은 숫자뿐입니다.

실측에서 가짜 키 값이 든 노트는 모델에 도달하지 않았고 `excluded: 1`로 보고됐습니다.

---

## 5. 설정 안 됨과 실패를 구분합니다

채팅 모델이 없는 것은 관리자가 1분이면 고치는 상태이고, 게이트웨이 장애는 아닙니다. 하나의 "답을 못 찾았습니다"로 뭉치면 어느 쪽인지 알 수 없습니다.

```
412  채팅 모델이 설정되지 않았습니다
     → 관리자 → AI Gateway에서 모델을 설정하면 됩니다. 임베딩 모델과는 별개입니다.
502  게이트웨이 호출 실패
```

임베딩 관문이 긋는 것과 같은 구분입니다.

프롬프트 인젝션 방어는 Dream이 쓰던 방식을 그대로 씁니다 — 사용자 데이터를 태그로 감싸고, 그 안의 명령을 따르지 말라고 명시합니다.

## 업그레이드

스키마 변경이 없습니다. 이미지만 교체하면 됩니다.

```bash
docker run -d --name umm --restart unless-stopped \
  -p 8080:8080 \
  -e POSTGRES_DSN='postgres://umm:password@postgres.internal:5432/umm?sslmode=require' \
  -e BOOTSTRAP_ADMIN='admin' \
  -e BOOTSTRAP_ADMIN_PASSWORD='your-strong-password' \
  -e ENCRYPTION_KEY='your-32-char-random-encryption-key' \
  umm:v0.22.0
```

- **채팅 모델이 필요합니다.** 임베딩 모델과 별개이며, 관리자 → Dream Layer의 모델 설정을 씁니다. 없으면 412와 함께 무엇을 하면 되는지 알려 줍니다.
- AI 일일 할당량을 소비하며 `ai:assist` scope가 필요합니다.
