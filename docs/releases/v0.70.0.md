# v0.70.0 — 그때의 공간

"석 달 전에 이 공간은 어떻게 생겼었지."

재료는 v0.2.0부터 쌓여 있었습니다. 메모를 고칠 때마다 **바뀌기 직전 상태**가 통째로
기록됩니다 — 글자만이 아니라 **어디에 놓여 있었는지까지**. 그걸 그렇게 읽는 코드가 없었을
뿐입니다.

```
        note_revisions
        ├─ content · title · color · kind
        └─ x · y · width · height · rotation   ← 자리까지 있습니다
```

## 규칙은 기록 방식에서 나옵니다

판본 행은 **그 변경이 덮어쓴 상태**를 담고, 시각은 **변경이 일어난 때**입니다. 따라서
어떤 시점의 상태는 **그 시점 이후에 기록된 가장 이른 판본**이고, 이후 기록이 없으면 그
뒤로 바뀐 적이 없다는 뜻이라 지금 상태가 그때 상태입니다.

- 그 뒤에 쓴 생각은 **없습니다**
- 그 뒤에 지운 생각은 **돌아옵니다** (그때는 캔버스에 있었으니까요)
- 연결은 **양쪽 끝이 이미 있던 것만** 그립니다

## 못 하는 것을 세어서 말합니다

**그 뒤에 지워진 연결은 되살릴 수 없습니다.** 삭제 이벤트는 처음부터 엣지 **id만** 담았고
(무엇과 무엇을 이었는지는 담은 적이 없습니다), 행 자체도 사라졌습니다.

그래서 조용히 빼지 않고 **몇 개인지 화면이 말합니다** — "그 뒤 지워진 연결 3개는 되살릴 수
없어 빠져 있습니다." 로그는 *무언가 지워졌다*는 것까지는 알고, 그 절반이 정직한 답입니다.

## 지나간 캔버스는 만질 수 없습니다

이게 이 기능에서 제일 위험한 부분입니다. 되감은 캔버스도 **캔버스처럼 생겼습니다** —
끌 수 있고, 고칠 수 있고, 저장됩니다. 거기서 한 변경은 **지금은 존재하지 않는 상태를
기준으로 오늘의 공간에 쓰이게** 됩니다.

그래서 되감기 조건을 **`readOnly` 안에** 넣었습니다.

```
readOnly = 권한이 보기 전용  ||  되감는 중
```

끌기·지우기·메모 메뉴·연결 패널·단축키까지 열일곱 곳이 **이미 이 하나를 읽고 있습니다.**
플래그를 따로 만들어 그 열일곱 곳에 다시 꿰면, 한 군데 빠뜨리는 순간 사라진 캔버스를
편집하게 됩니다. 이 세션에서 계속 나온 그 모양입니다.

### 읽기 전용이라고만 하면 거짓말입니다

기존 문구는 **"읽기 전용으로 공유된 공간입니다"** 였습니다. 자기 공간을 되감아 보는
사람에게 **공유된 적 없는 사실**을 말하게 됩니다. 이유에 따라 갈랐습니다 — 되감는 중에는
"지나간 시점을 보고 있어 바꿀 수 없습니다."

### 남이 고쳐도 화면이 오늘로 변하지 않습니다

실시간 스트림은 다른 사람의 변경에 캔버스를 다시 불러옵니다. 되감는 중이면 **건너뜁니다.**
과거를 보던 사람이 아무 말 없이 오늘을 보게 되는 일은 없어야 합니다.

## 시험이 규칙을 확인하지 못하고 있었습니다

변형 일곱 개 중 하나가 통과했습니다 — "가장 이른 판본" 대신 "가장 늦은 판본"을 고르는
변형입니다. **제 시험이 전부 수정을 한 번만 했기 때문입니다.** 한 번이면 둘이 같은 행을
고릅니다.

세 번 고친 메모를 놓고 **세 시점**을 확인하게 바꿨습니다. 두 수정 사이의 시점에서 답이
갈립니다. 고친 뒤 같은 변형이 잡혔습니다.

## 확인한 것

```
✓ 그때의 문장과 그때의 자리
✓ 나중에 쓴 생각은 없음
✓ 나중에 지운 생각은 돌아오고, 오늘 캔버스에는 없음
✓ 한쪽 끝이 없던 연결은 안 그림
✓ 지워진 연결은 안 그리고, 몇 개인지 셈
✓ 못 보는 사람에게는 "빈 공간"이 아니라 거절
✓ 세 판본 · 세 시점에서 각각 맞는 판본
✓ 브라우저: 되감으면 오늘 것이 사라지고, 읽기 전용이 되고, 돌아오면 돌아옴
```

| 바꾼 것 | 잡은 것 |
| :--- | :--- |
| 오늘 문장을 과거로 | 그때가 오늘이 됨 |
| 가장 늦은 판본을 고름 | (처음엔 **못 잡음** → 시험을 고침) |
| 나중 생각을 과거에 | 없던 생각이 있음 |
| 지운 생각을 안 되살림 | 있던 생각이 없음 |
| 없던 끝점에 연결 | 허공으로 가는 선 |
| 지워진 연결 수를 안 셈 | 빠진 걸 화면이 모름 |
| 접근 권한 검사 제거 | 남의 공간을 봄 |
| 되감기를 `readOnly`에서 뺌 | 사라진 캔버스를 편집 |
| 공유 문구를 그대로 씀 | 없던 공유를 말함 |
| "지금으로"가 안 돌아옴 | 과거에 갇힘 |
