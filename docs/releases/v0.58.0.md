# v0.58.0 — 저장하기 전에 무슨 일이 일어나는지 봅니다

관리 기능 고도화, 마지막 네 번째입니다.

`관리 → 유사도 기준`에는 숫자를 넣는 칸이 두 개 있었습니다. **연관 생각 기준 0.6**,
**군집 기준 1.1.** 설명은 "낮을수록 더 많이 연관으로 봅니다"였습니다.

얼마나 더요?

기준은 코사인 값이 아니라 **그 공간 자기 점수의 평균에서 표준편차 몇 개 위인가**입니다.
그래서 같은 0.6이 코퍼스에 따라 전혀 다른 일을 합니다. 알아낼 방법은 하나뿐이었습니다.
**저장하고 가서 보기.** 저장하면 설치된 모든 캔버스가 한꺼번에 바뀌고, 바꾼 사람이 가장
늦게 압니다.

## 이제 재봅니다

기준을 고친 뒤 **지금 값으로 재보기** 를 누릅니다. 아무것도 저장하지 않습니다.

```
                          지금 (0.6 / 1.1)    바꾸면 (2.5 / 1.1)
연관 생각이 하나도 없는 카드         0                 218 (+218)
카드당 연관 생각 (중앙값)           11                   0 (-11)
가장 많은 카드                     11                   0 (-11)
묶음 수                            9                    9
묶인 생각                        204                  204
가장 큰 묶음                       31                   31
혼자 남는 생각                     37                   37
```

**연관 생각이 하나도 없는 카드**가 가장 먼저 볼 숫자입니다. 기준을 너무 올리면 서서히
나빠지는 것이 아니라 **패널이 그냥 비어 버립니다.**

## 무엇으로 재는가

가장 큰 공간 다섯 개, 공간마다 400개까지. 비교는 공간 안에서 제곱으로 늘어나고 관리자가
기다리는 동안 돌기 때문에 표본을 씁니다. 생각 아홉 개짜리 공간은 아무에게도 아무것도
말해 주지 않습니다.

**임베딩이 없는 생각은 어느 기준의 답에도 들어 있지 않습니다.** 그래서 몇 개가 임베딩돼
있는지 같이 적습니다 — "이 변경은 아무것도 묶지 않습니다"와 "여기 있는 것 중 아직 아무것도
임베딩되지 않았습니다"는 완전히 다른 말입니다.

임베딩이 의미 비교에 부적합하다고 판정돼 있으면 캔버스는 위치로 묶으므로 **군집 기준은
아무 일도 하지 않습니다.** 그럴 때는 숫자 대신 그 사실을 알려 줍니다. 아무도 보지 못할
산술을 설명하지 않습니다.

## 범위 밖 값은 거절합니다

0에서 4 밖의 값은 400으로 돌려보냅니다. 설정이 조용히 기본값으로 바꿔치기하는 값을
미리 보여 주면, **아무도 요청하지 않은 설정을 설명하는 셈**이 됩니다.

## 확인한 것

```
✓ 3.5로 올리면 24장 전부 연관 생각이 비고, 묶음이 사라짐
✓ 0.2로 내리면 다시 채워지고 묶임
✓ 무엇을 제안하든 "지금" 칸은 실제로 적용 중인 설정 그대로
✓ 묶인 생각 + 혼자 남는 생각 = 임베딩된 생각 (두 기준 모두)
✓ 미리 본 뒤에도 저장된 설정은 그대로
✓ 9, -1, abc, NaN 은 400
```

시험이 실제로 실패하는지도 확인했습니다. 서버가 제안된 기준 대신 현재 기준을 쓰게 바꾸자
**3.5인데도 24장이 다 채워져 있는 것을 잡았고**, 혼자인 씨앗을 한 개짜리 묶음으로 세게
바꾸자 **없어야 할 묶음 24개를 잡았습니다.** 화면 쪽에서는 입력한 값을 요청에 싣지 않게
바꾸자 **e2e가 잡았습니다** — 번들 해시가 실제로 바뀐 것을 확인한 뒤였습니다.

## 재던 중에 알게 된 것

시험용으로 서로 어휘가 겹치지 않는 두 주제를 24개 넣었더니 **기본 군집 기준 1.1이
아무것도 묶지 않았습니다.** 버그가 아닙니다. 점수 분포가 둘로 갈라지면 평균+1.1σ가
같은 주제 안의 점수보다도 위에 놓입니다. 처음 쓴 시험은 이걸 모르고 "기본값보다 올리면
덜 묶인다"를 전제했다가 틀렸고, 이제 **제안 두 개를 서로 비교**합니다.
